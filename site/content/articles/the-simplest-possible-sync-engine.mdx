# A small sync path with Durable Streams and TanStack DB

A browser can answer queries from local collections while an ordered stream
brings in server changes. Streamsy's Hacker News demo makes that path concrete:
an Effect server polls stories, appends source changes, projects State facts and
serves them over the Durable Streams protocol.

![Request-based architecture puts the network on the query path, while sync-based architecture keeps queries local.](/articles/sync-vs-request-architecture.svg)

## Three pieces

The server uses Streamsy's protocol services and a SQLite Layer. A declared-output
projection turns source upserts and deletes into State facts with source positions.
The browser uses the official `@durable-streams/state/db` integration to maintain
TanStack DB collections. React live queries then render those local collections.

![State facts travel over Durable Streams into TanStack DB, which serves live queries to the UI.](/articles/durable-state-tanstack-db.svg)

State facts identify an entity type and key, carry its new value for an upsert,
and describe the operation in headers. The source offset connects output to the
source boundary. These facts are the contents of the stream; the HTTP protocol
carries them without interpreting the application's entity model.

## Read the running code

The compiled [browser entry](https://github.com/gingerhendrix/streamsy/blob/effect/examples/hackernews-newest-stream/src/client/main.tsx)
creates the official StreamDB from the target URL and shared state schema,
preloads it and closes it with the React lifecycle. The compiled
[server entry](https://github.com/gingerhendrix/streamsy/blob/effect/examples/hackernews-newest-stream/src/server/index.ts)
owns the shared SQLite services, polling and HTTP edge.

The [Introduction](/docs/introduction) walks through the public Streamsy
toolkit and Bun host. The first release packages are `@streamsy/core`,
`@streamsy/storage`, `@streamsy/projection`, `@streamsy/serve` and
`@streamsy/views`. Effect is the server and toolkit boundary; official Durable
Streams packages supply the browser path.

## What this demo establishes

The [Hacker News demo](/docs/demos/hackernews-newest-stream) shows initial catch-up,
updates and deletes in a browser collection. Its `Projection.stream` declaration
pins input ranges and producer position before appending, so a retry reproduces
the same unit and producer tuple.

This demo deliberately uses one acquired SQLite store for streams and projection
checkpoints, with `HN_DB=memory` as an explicit ephemeral option. The local
Cloudflare Durable Object host is implemented with workerd evidence; hosted
execution and release acceptance remain pending. See the [Cloudflare
guide](/docs/runtime/cloudflare).
