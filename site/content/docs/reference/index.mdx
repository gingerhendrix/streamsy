---
title: How the reference works
description: One page for each group of exports in the @streamsy packages. Every signature on these pages is checked against the package at build.
---

The guides show how to use Streamsy. These pages list what each package exports.

Each page starts with the import that it uses. Then each export has a section with:

- its signature, as you would write it after that import;
- what it does, and the rules that the signature does not show;
- a link to the guide that uses it, when one exists.

The site build compares each signature with the real export. A signature that no longer matches the package stops the build.

| Page                                                            | Exports                                                             |

| [Streamsy](/docs/reference/core/streamsy)                       | The stream class factories, `group`, `Wildcard` and the class types |

These pages cover the application exports of the `@streamsy/core` root. The storage contract exports, the `Http` namespace, the `/remote`, `/protocol` and `/testing` entry points, and the other packages do not have reference pages yet.
