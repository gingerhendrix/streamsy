---
title: How the reference works
description: One page for each group of exports in the @streamsy packages. Every signature on these pages is checked against the package at build.
---

The guides show how to use Streamsy. The reference pages list what each package exports and the rules for each export.

Each page starts with the import that its signatures use. Each export then has a section with three parts:

- the signature, written as you would write it after that import
- what the export does, and the rules that the signature does not show
- a link to the guide that uses the export, when one exists

The site build compares each signature on these pages with the real export. When a package changes and a page does not, the build fails and names the page.

## `@streamsy/core`

| Page                                                            | Exports                                                             |
| --------------------------------------------------------------- | ------------------------------------------------------------------- |
| [Streamsy](/docs/reference/core/streamsy)                       | The stream class factories, `group`, `Wildcard` and the class types |
| [StreamAddress](/docs/reference/core/stream-address)            | Addresses, collections, and the State changes and controls          |
| [Producer](/docs/reference/core/producer)                       | `Producer.Position`, `Producer.next`                                |
| [DurableState](/docs/reference/core/durable-state)              | `upsert`, `remove`, `changes` and their types                       |
| [Options and results](/docs/reference/core/options-and-results) | The options of create, append and read, and their results           |
| [Toolkit types](/docs/reference/core/toolkit)                   | `Batch`, the fold and decide types, and the failure unions          |
| [Errors](/docs/reference/core/errors)                           | The protocol errors, the error unions, `isProtocolError`            |
| [Faults](/docs/reference/core/faults)                           | The storage, transport and codec faults, and their guards           |

These pages cover the exports of the `@streamsy/core` root that an application uses. The storage contract, the `Http` namespace, the `/remote`, `/protocol`, and `/testing` entry points, and the other packages have no reference pages yet.
