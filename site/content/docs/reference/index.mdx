---
title: How the reference works
description: One page for each group of exports in the @streamsy packages. Every signature on these pages is checked against the package at build.
---

The guides show how to use Streamsy. The reference pages list what each package exports and the rules for each export.

Each page starts with the import that its signatures use. Each export then has a section with three parts:

- the signature, written as you would write it after that import
- what the export does, and the rules that the signature does not show
- a link to the guide that uses the export, when one exists

The site build compares each signature on these pages with the real export. When a package changes and a page does not, the build fails and names the page.

These pages cover the public entry points of `@streamsy/core` (the root, `/http`, `/remote`, `/protocol`, and `/testing`), of `@streamsy/projection` (the root and `/checkpoint`), of `@streamsy/storage` (the root, `/bun`, and `/durable-object`), and of `@streamsy/serve` (the root, `/contract`, `/action`, `/action/errors`, `/action/outbox`, `/action/runtime`, and `/action/sql`). The serve host entry points have no reference pages yet.
