`Deno.listener` is the HTTP listener Layer of a Streamsy host on Deno. Provide it to [`Serve.layer`](/docs/reference/serve/serve#servelayer). See [host Layers](/docs/hosting#layers) and [long-running hosts](/docs/http/serve#long-running-hosts).

## Listener

### `Deno.listener`

```ts
// ---cut-start---
import * as Deno from "@streamsy/serve/deno";
import type { Duration, Effect, Layer } from "effect";
import type { Etag, HttpPlatform, HttpServer, HttpServerError } from "effect/http";
import type { Crypto, FileSystem, Path, Stdio, Terminal } from "effect";
import type { ChildProcessSpawner } from "effect/process";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function listener(
  options?: Deno.ListenerOptions,
): Layer.Layer<
  | Etag.Generator
  | HttpPlatform.HttpPlatform
  | HttpServer.HttpServer
  | ChildProcessSpawner.ChildProcessSpawner
  | Crypto.Crypto
  | FileSystem.FileSystem
  | Path.Path
  | Stdio.Stdio
  | Terminal.Terminal,
  HttpServerError.ServeError,
  never
>;
// ---cut-after---
same<typeof listener, typeof Deno.listener>(true);
```

`Deno.listener` binds the port when its Layer builds, and closes the server when the scope of the Layer closes. When the bind fails, the Layer fails with `HttpServerError.ServeError`. The Layer requires no services.

The listener binds port 3000 on `127.0.0.1` unless the options set others. Without `gracefulShutdownTimeout`, the listener turns off the preemptive shutdown of the platform server, and its scope finalizer waits for in-flight requests to end. With `gracefulShutdownTimeout`, the platform server stops waiting after that time.

The Deno HTTP server has no idle or response timeout that cuts off a parked long poll or an SSE body.

### `Deno.nodeSqliteCompat`

```ts
// ---cut-start---
import * as Deno from "@streamsy/serve/deno";
import type { Duration, Effect, Layer } from "effect";
import type { Etag, HttpPlatform, HttpServer, HttpServerError } from "effect/http";
import type { Crypto, FileSystem, Path, Stdio, Terminal } from "effect";
import type { ChildProcessSpawner } from "effect/process";
import { same } from "./reference-check.ts";
// ---cut-end---
declare const nodeSqliteCompat: Effect.Effect<void, never, never>;
// ---cut-after---
same<typeof nodeSqliteCompat, typeof Deno.nodeSqliteCompat>(true);
```

`Deno.nodeSqliteCompat` adds a no-op `enableLoadExtension` method to the `node:sqlite` `DatabaseSync` prototype when that method is absent. It leaves an existing method unchanged.

Run this Effect before the first `SqliteClient.make` from `@effect/sql-sqlite-node`. That driver calls `enableLoadExtension(false)` on each open, and on Deno that call throws without this method. When the import of `node:sqlite` fails, the Effect dies.

## Options

### `Deno.ListenerOptions`

```ts
// ---cut-start---
import * as Deno from "@streamsy/serve/deno";
import type { Duration, Effect, Layer } from "effect";
import type { Etag, HttpPlatform, HttpServer, HttpServerError } from "effect/http";
import type { Crypto, FileSystem, Path, Stdio, Terminal } from "effect";
import type { ChildProcessSpawner } from "effect/process";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ListenerOptions {
  readonly port?: number;
  readonly hostname?: string;
  readonly gracefulShutdownTimeout?: Duration.Input;
}
// ---cut-after---
same<ListenerOptions, Deno.ListenerOptions>(true);
```

`Deno.ListenerOptions` holds the options of `Deno.listener`.

| Field                     | Default     | Meaning                                                 |
| ------------------------- | ----------- | ------------------------------------------------------- |
| `port`                    | 3000        | The port to bind                                        |
| `hostname`                | `127.0.0.1` | The address to bind                                     |
| `gracefulShutdownTimeout` | Unset       | The longest wait for in-flight requests during shutdown |

## Defaults

### `Deno.DEFAULT_PORT`

```ts
// ---cut-start---
import * as Deno from "@streamsy/serve/deno";
import type { Duration, Effect, Layer } from "effect";
import type { Etag, HttpPlatform, HttpServer, HttpServerError } from "effect/http";
import type { Crypto, FileSystem, Path, Stdio, Terminal } from "effect";
import type { ChildProcessSpawner } from "effect/process";
import { same } from "./reference-check.ts";
// ---cut-end---
declare const DEFAULT_PORT: 3000;
// ---cut-after---
same<typeof DEFAULT_PORT, typeof Deno.DEFAULT_PORT>(true);
```

`Deno.DEFAULT_PORT` is the default port of `Deno.listener`: 3000.
