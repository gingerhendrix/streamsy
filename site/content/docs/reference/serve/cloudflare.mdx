---
title: Cloudflare
description: Reference for the host exports in @streamsy/serve/cloudflare. They route protocol requests to Durable Objects and schedule work over each object's storage.
---

```ts
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
```

The Cloudflare host sends each protocol request to the Durable Object that owns the stream. Each object has its own storage, routes, and alarm. See [Cloudflare hosting](/docs/hosting/cloudflare).

## Object host

### `Cloudflare.StreamsyObject`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare const StreamsyObject: {
  make: <Env = unknown, R = never, L = never>(
    configuration: Cloudflare.ObjectConfiguration<Env, R, L>,
  ) => new (state: Workers.DurableObjectState, env: Env) => ObjectHost<Env, R, L>;
};

// ObjectHost has no exported name. Keep the package's nominal instance type,
// which extends the platform DurableObject and implements ObjectInstance.
type ObjectHost<Env, R, L> = InstanceType<
  ReturnType<typeof Cloudflare.StreamsyObject.make<Env, R, L>>
>;
// ---cut-after---
same<typeof StreamsyObject, typeof Cloudflare.StreamsyObject>(true);
same<
  Pick<InstanceType<ReturnType<typeof StreamsyObject.make>>, keyof Cloudflare.ObjectInstance>,
  Cloudflare.ObjectInstance
>(true);
```

`Cloudflare.StreamsyObject.make` returns a Durable Object class for an `ObjectConfiguration`. On the first fetch or alarm, the object acquires its storage and builds its routes. After an acquisition succeeds, every later fetch and alarm reuses it.

When the acquisition fails, `fetch` answers 503 with `Retry-After: 1`, and the next fetch or alarm acquires again. The host closes the scope of the failed acquisition first. When the acquisition fails during an alarm, the alarm Promise rejects, so the platform retries the alarm.

The host reconciles the wakeup due times after the acquisition, and after every PUT, POST, and DELETE request, rejected requests included. It also reconciles after a request that calls `Wakeups.touch`. When a route dies, the object answers 500 with the protocol security headers. The object does not log requests.

### `Cloudflare.ObjectConfiguration`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ObjectConfiguration<Env, R = never, L = never> {
  readonly app: ObjectApp<R | L>;
  readonly wakeups?: ReadonlyArray<Cloudflare.WakeupSource<Storage | R | L>>;
  readonly layer: (
    state: Workers.DurableObjectState,
    env: Env,
  ) => Layer.Layer<Storage | R, StorageFault, L>;
  readonly links?: (env: Env) => ReadonlyArray<Cloudflare.LinkClient<L>>;
}

// ObjectApp has no exported name. It is the route Layer that the object hosts accept.
type ObjectApp<R = never> = Layer.Layer<
  never,
  never,
  | HttpRouter.HttpRouter
  | HttpRouter.Request.From<"Requires", Storage | Cloudflare.Wakeups | R>
  | HttpRouter.Request.From<"Error", HttpServerRespondable.Respondable>
>;
// ---cut-after---
same<ObjectConfiguration<unknown>, Cloudflare.ObjectConfiguration<unknown>>(true);
same<
  ObjectConfiguration<
    { readonly binding: string },
    { readonly local: "local" },
    { readonly linked: "linked" }
  >,
  Cloudflare.ObjectConfiguration<
    { readonly binding: string },
    { readonly local: "local" },
    { readonly linked: "linked" }
  >
>(true);
```

`Cloudflare.ObjectConfiguration` holds the routes, the local services, the wakeups, and the links of one object class.

| Field     | Meaning                                                                                             |
| --------- | --------------------------------------------------------------------------------------------------- |
| `app`     | The route Layer. It can use storage, `Wakeups`, the local services `R`, and the linked services `L` |
| `layer`   | Builds the Layer of local storage and services from the object state and the environment            |
| `wakeups` | More wakeups. The host always adds stream expiry                                                    |
| `links`   | Builds the clients of streams that live on other objects                                            |

The host provides the alarm slot from `state.storage`. It builds the linked services before the local Layer, so the local Layer can use them. When the local Layer also provides a linked stream, the acquisition fails with `StorageFault`. Keep linked streams out of the local storage group.

## Worker routing and placement

### `Cloudflare.router`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function router<Env>(options: Cloudflare.RouterOptions<Env>): Workers.ExportedHandler<Env>;
// ---cut-after---
same<typeof router, typeof Cloudflare.router>(true);
```

`Cloudflare.router` returns a Worker fetch handler that forwards each protocol request to the object that placement names. Placement gets the stream path without the mount prefix. The object gets the original request unchanged, with its encoded path segments, query, headers, and body. The router sends a fork request to the object of the child stream.

Authenticate the caller before you pass the request to the router. The router serves protocol paths only, so route Serve paths in your own Worker code.

| Condition                                     | Response                       |
| --------------------------------------------- | ------------------------------ |
| Path starts with `/__`                        | 404, without calling an object |
| Path has no stream id under the prefix        | 400, without calling an object |
| Placement returns an empty or non-string name | 400, without calling an object |
| Placement throws                              | 500, without calling an object |

A fork source and its child must live on the same object. Do not change the placement of an object that holds data.

### `Cloudflare.rule`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function rule<Params>(spec: OwnerRule<Params>): ErasedOwnerRule;

// These rule shapes have no exported names. OwnerRule keeps the type of the
// decoded params. ErasedOwnerRule hides it, so one byRoute table can hold rules
// with different params.
interface OwnerRule<Params> {
  readonly stream: { parse(id: string): Option.Option<Params> };
  owner(params: Params): string;
}
interface ErasedOwnerRule {
  readonly stream: { parse(id: string): Option.Option<unknown> };
  owner(params: never): string;
}
// ---cut-after---
same<typeof rule, typeof Cloudflare.rule>(true);
```

`Cloudflare.rule` returns `spec` with `owner` typed to take the decoded params of `stream`. Pass the result to `Placement.byRoute`. `owner` has method syntax, so the compiler still infers the params of each `owner`, and one table can hold rules with different params.

### `Cloudflare.Placement`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface Placement {
  readonly name: (streamPath: string) => string;
}

declare const Placement: {
  readonly byStream: () => Cloudflare.Placement;
  readonly byKey: (key: (streamPath: string) => string) => Cloudflare.Placement;
  readonly byRoute: (rules: ReadonlyArray<ErasedOwnerRule>) => Cloudflare.Placement;
};

// ErasedOwnerRule has no exported name. Build these values with rule.
interface ErasedOwnerRule {
  readonly stream: { parse(id: string): Option.Option<unknown> };
  owner(params: never): string;
}
// ---cut-after---
same<Placement, Cloudflare.Placement>(true);
same<typeof Placement, typeof Cloudflare.Placement>(true);
```

`Cloudflare.Placement` names the object that owns a stream path. It has three constructors:

| Constructor      | Object name                                                       |
| ---------------- | ----------------------------------------------------------------- |
| `byStream()`     | The stripped stream path, unchanged                               |
| `byKey(key)`     | The result of `key(streamPath)`                                   |
| `byRoute(rules)` | The `owner` result of the first rule whose stream parses the path |

When the stream of a rule cannot decode a segment, `byRoute` tries the next rule. When no rule matches, `byRoute` returns an empty string, and the router answers 400.


`Cloudflare.RouterOptions` holds the object namespace, the placement, and the protocol mount prefix of `router`.

| Field       | Default                | Meaning                                                                  |
| ----------- | ---------------------- | ------------------------------------------------------------------------ |
| `namespace` | Required               | Returns the Durable Object namespace binding from the Worker environment |
| `placement` | `Placement.byStream()` | Names the object of each stream path, without the prefix                 |

The router adds a trailing slash to the prefix when it has none, and then strips the prefix from each path. The object gets the original path, so its protocol mount must use the same prefix.

## Wakeups

### `Cloudflare.Wakeup`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface Wakeup<R = never> {
  readonly name: string;
  readonly next: Effect.Effect<Option.Option<number>, StorageFault, R>;
  readonly run: Effect.Effect<void | Cloudflare.WakeupProgress, unknown, R>;
  readonly retry?: Schedule.Schedule<unknown>;
}

declare const Wakeup: {
  make: <R>(wakeup: Cloudflare.Wakeup<R>) => Cloudflare.Wakeup<R>;
};
// ---cut-after---
same<Wakeup, Cloudflare.Wakeup>(true);
same<Wakeup<{ readonly dependency: string }>, Cloudflare.Wakeup<{ readonly dependency: string }>>(
  true,
);
same<typeof Wakeup, typeof Cloudflare.Wakeup>(true);
```

`Cloudflare.Wakeup` is one kind of scheduled work in an object: a bounded, idempotent `run`, and a `next` that reads its due time from committed state. `Wakeup.make` runs `run` under the permit of the object for that name. The permit is not reentrant, so a `run` must not call its own `run`.

| Field   | Meaning                                                                                                        |
| ------- | -------------------------------------------------------------------------------------------------------------- |
| `name`  | A name unique in the object. Stream expiry uses `streamsy/expiry`                                              |
| `next`  | The next due time in epoch milliseconds, or `None` when there is no work                                       |
| `run`   | The work, which can run more than once. Returns `{ more: true }` when it stops at its bound with due work left |
| `retry` | The schedule whose delays set the earliest retry time after a failure                                          |

The host runs stream expiry first, and then the other wakeups in declaration order. Two wakeups with the same name fail the acquisition. When one wakeup fails in `next` or `run`, the others still run.

Without `retry`, the backoff after each failure doubles from 1 second, up to 1 hour. A run that reports no more work also backs off when work that was due before it started is still due. When a finite `retry` schedule ends, the host stops retrying. A run that makes progress resets the failure count. The backoff state is in memory, so an eviction clears it.

### `Cloudflare.Wakeups`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";
import type { HttpClientError, HttpRouter, HttpServerRespondable } from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
class Wakeups extends Context.Service<
  Wakeups,
  {
    readonly touch: Effect.Effect<void, never, never>;
    readonly reconcile: Effect.Effect<void, never, never>;
    readonly status: Effect.Effect<
      ReadonlyArray<{
        readonly name: string;
        readonly next: Option.Option<number>;
        readonly failures: number;
        readonly retryAt: Option.Option<number>;
      }>,
      never,
      never
    >;
  }
>()("@streamsy/serve/cloudflare/Wakeups") {}
// ---cut-after---
same<typeof Wakeups, typeof Cloudflare.Wakeups>(true);
same<Wakeups, Cloudflare.Wakeups>(true);
```

`Cloudflare.Wakeups` is the service key of the wakeup scheduler of an object.

| Member      | Meaning                                                                                               |
| ----------- | ----------------------------------------------------------------------------------------------------- |
| `touch`     | Marks the current request, so the host reconciles when its handler returns                            |
| `reconcile` | Reads the due times and arms the alarm for the earliest one, or clears the alarm when no work remains |
| `status`    | Reads the due time, the failure count, and the retry time of each wakeup                              |

Call `touch` before the handler returns. When a streamed body queues work after the handler returns, call `reconcile` instead. Work outside a request also calls `reconcile`.

`reconcile` does not run due work inside the request. It arms the alarm for `now + 1` instead. An alarm turn arms a recovery alarm 30 seconds ahead before it runs due work, and reconciles again after the work. In `status`, `retryAt` is the earliest time at which the backoff lets the wakeup run. When `next` fails inside `status`, `status` dies.

## Object clients and links

### `Cloudflare.ObjectStreams`

```ts

```

`Cloudflare.ObjectStreams.layer` provides stream services that send each request to the owner object through its stub, not over the network. The owner must serve an `Http.routes` mount at `prefix`. The client declares that the owner supports producers and expected offsets.

The client answers 404 without calling an object when a request is outside the prefix or the group. A placement failure answers 400 or 500, as in [`router`](#cloudflarerouter). An Effect transport gets the context, the tracing, and the interruption of the caller.

### `Cloudflare.ObjectLink`

```ts
// ---cut-start---

  readonly routes: Cloudflare.LinkRoutes<Streamsy.Services<Streamsy.Group<Keys>>>;
  readonly client: (
    objects: Workers.DurableObjectNamespace | Cloudflare.ObjectFetch,
  ) => Cloudflare.LinkClient<Streamsy.Services<Streamsy.Group<Keys>>>;
}

declare const ObjectLink: {
  readonly make: <const Keys extends ReadonlyArray<Streamsy.Any>>(
    options: Cloudflare.ObjectLinkOptions<Keys>,
  ) => Cloudflare.ObjectLink<Keys>;

// ---cut-after---
same<
  ObjectLink<readonly [typeof Streamsy.Wildcard]>,
  Cloudflare.ObjectLink<readonly [typeof Streamsy.Wildcard]>
>(true);
same<typeof ObjectLink, typeof Cloudflare.ObjectLink>(true);
```

`Cloudflare.ObjectLink.make` declares a link: an internal mount on the owner object, and the client that other objects use to reach it. Add `routes` to the app of the owner, and return `client(objects)` from the `links` of each caller.

`make` throws a `RangeError` unless the prefix starts with `/__` followed by a character other than `/`. The usual protocol prefix checks also apply. The public routers of the package reject a reserved path before they call an object.

`access` applies to every stream of the link, Durable State wake streams included. Use `full` when the producer must create a missing wake stream with PUT. A link trusts any caller that holds a stub of the object. See [Streams on other objects](/docs/hosting/cloudflare#streams-on-other-objects).

### `Cloudflare.LinkAccess`

```ts
// ---cut-start---

// ---cut-end---
type LinkAccess = "read" | "append" | "full";
// ---cut-after---
same<LinkAccess, Cloudflare.LinkAccess>(true);
```

`Cloudflare.LinkAccess` sets the methods that the owner mount of a link allows. `read` allows OPTIONS, GET, and HEAD. `append` adds POST, and `full` adds PUT and DELETE. A method that the access does not allow gets 405.

### `Cloudflare.LinkClient`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";

// ---cut-end---
interface LinkClient<I> {
  readonly streams: ReadonlyArray<Streamsy.Any>;
  readonly layer: Layer.Layer<I, never, never>;
}
// ---cut-after---
same<LinkClient<{ readonly linked: string }>, Cloudflare.LinkClient<{ readonly linked: string }>>(
  true,

```

`Cloudflare.LinkClient` is the client side of a link in a caller object. `streams` lists the remote stream classes, and `layer` provides their clients. During the acquisition, the host checks that the local Layer provides none of `streams`.

### `Cloudflare.LinkRoutes`

```ts
// ---cut-start---
import * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import { Context, type Effect, type Layer, type Option, type Schedule, type Scope } from "effect";

import { same } from "./reference-check.ts";
// ---cut-end---
type LinkRoutes<I> = Layer.Layer<
  never,
  never,
  HttpRouter.HttpRouter | HttpRouter.Request.From<"Requires", Exclude<I, HttpRouter.Provided>>
>;
// ---cut-after---
same<LinkRoutes<never>, Cloudflare.LinkRoutes<never>>(true);

```

`Cloudflare.LinkRoutes` is the route Layer of a link on the owner object. Its request requirements are the linked stream services that the router does not provide itself.
