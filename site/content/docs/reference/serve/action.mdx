---
title: Action sinks
description: Reference for the action sink exports in @streamsy/serve/action. They declare payload identity, handlers, and retry policy.
---

```ts
import {
  defineActionSink,
  backoffAfter,
  type ActionSinkRelation,
  type ActionSinkChange,
  type ActionSinkHandlerRef,
  type ActionSinkDeliveryPolicy,
  type ActionSinkPayloadCodec,
  type ActionSinkSpec,
  type CheckedActionSink,
  type PayloadOf,
} from "@streamsy/serve/action";
```

An action sink declares external effects for changes to a keyed relation. See [Declare a sink](/docs/projections/actions#declare-a-sink).

## `defineActionSink`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { ActionSinkRelation, ActionSinkSpec, CheckedActionSink } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function defineActionSink<Payload, From extends ActionSinkRelation>(
  spec: ActionSinkSpec<Payload, From>,
): CheckedActionSink<Payload, From>;
// ---cut-after---
same<typeof defineActionSink, typeof Real.defineActionSink>(true);
```

`defineActionSink` validates the retry policy and returns a shallow-frozen declaration. It performs no I/O.

When `maxAttempts` is not an integer of at least 1, `backoffFactor` is below 1, `initialBackoffMs` is negative, or `maxBackoffMs` is below `initialBackoffMs`, `defineActionSink` throws a `TypeError`.

The fingerprint covers the sink name, relation key, handler reference, and delivery policy. It excludes the codec, idempotency function, and partition function. The returned `key` comes from `spec.from.key`.

## `backoffAfter`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { ActionSinkDeliveryPolicy } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function backoffAfter(policy: ActionSinkDeliveryPolicy, attempts: number): number;
// ---cut-after---
same<typeof backoffAfter, typeof Real.backoffAfter>(true);
```

`backoffAfter` computes the delay after `attempts` failed attempts. It rounds `initialBackoffMs * backoffFactor ** Math.max(0, attempts - 1)` and caps the result at `maxBackoffMs`. It does not schedule a retry.


`ActionSinkRelation` identifies the declared key of the relation that a sink observes. The sink carries this key into `CheckedActionSink.key`.

## `ActionSinkChange`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
type ActionSinkChange<Row, Key = string> =
  | { readonly kind: "enter"; readonly key: Key; readonly after: Row }
  | { readonly kind: "update"; readonly key: Key; readonly before: Row; readonly after: Row }
  | { readonly kind: "exit"; readonly key: Key; readonly before: Row };
// ---cut-after---
same<
  ActionSinkChange<{ readonly id: number }, number>,
  Real.ActionSinkChange<{ readonly id: number }, number>
>(true);
same<ActionSinkChange<string>, Real.ActionSinkChange<string>>(true);
```

`ActionSinkChange` describes a row entering, changing within, or leaving the observed relation. An `enter` has the new row, an `update` has both rows, and an `exit` has the old row.

```ts
// ---cut-start---

interface ActionSinkHandlerRef {
  readonly name: string;
  readonly version: number;
}
// ---cut-after---
same<ActionSinkHandlerRef, Real.ActionSinkHandlerRef>(true);
```

`ActionSinkHandlerRef` names the handler and its version. Both fields contribute to the sink fingerprint. The reference declares identity. It does not register or resolve a handler.

## `ActionSinkDeliveryPolicy`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkDeliveryPolicy {
  readonly maxAttempts: number;
  readonly initialBackoffMs: number;
  readonly backoffFactor: number;
  readonly maxBackoffMs: number;
}
// ---cut-after---
same<ActionSinkDeliveryPolicy, Real.ActionSinkDeliveryPolicy>(true);
```

`ActionSinkDeliveryPolicy` sets the retry budget and backoff.

| Field              | Meaning                                                                          |
| ------------------ | -------------------------------------------------------------------------------- |
| `maxAttempts`      | Total attempts, including the first. A value of 1 dead-letters the first failure |
| `initialBackoffMs` | Delay after the first failed attempt, in milliseconds                            |
| `backoffFactor`    | Multiplier for each later delay                                                  |
| `maxBackoffMs`     | Upper bound on the rounded delay. `Infinity` leaves it uncapped                  |

The outbox stores the next attempt time, so a restart retains the retry deadline. `defineActionSink` enforces the policy limits described above.

## `ActionSinkPayloadCodec`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkPayloadCodec<Payload> {
  readonly encode: (payload: Payload) => string;
  readonly decode: (value: unknown) => Payload;
}
// ---cut-after---
same<
  ActionSinkPayloadCodec<{ readonly id: string }>,
  Real.ActionSinkPayloadCodec<{ readonly id: string }>
>(true);
```

`ActionSinkPayloadCodec` encodes a typed payload as stored JSON text and decodes the parsed value. `drain` calls `JSON.parse` before `decode`. When either step throws, `drain` dead-letters the entry as `payload-poison` without calling the handler.

## `ActionSinkSpec`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type {
  ActionSinkRelation,
  ActionSinkDeliveryPolicy,
  ActionSinkHandlerRef,
  ActionSinkPayloadCodec,
} from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkSpec<Payload, From extends ActionSinkRelation = ActionSinkRelation> {
  readonly name: string;
  readonly from: From;
  readonly handler: ActionSinkHandlerRef;
  readonly payload: ActionSinkPayloadCodec<Payload>;
  readonly idempotencyKey: (payload: Payload) => string;
  readonly partitionBy: (payload: Payload) => string;
  readonly delivery: ActionSinkDeliveryPolicy;
}
// ---cut-after---
same<ActionSinkSpec<string>, Real.ActionSinkSpec<string>>(true);
same<
  ActionSinkSpec<number, { readonly key: "id" }>,
  Real.ActionSinkSpec<number, { readonly key: "id" }>
>(true);
```

`ActionSinkSpec` declares the relation, handler, payload codec, durable identity, lane, and retry policy of a sink.

| Field            | Meaning                                                                             |
| ---------------- | ----------------------------------------------------------------------------------- |
| `name`           | Sink name, used with the idempotency key to deduplicate enqueues                    |
| `from`           | Observed relation and its declared key                                              |
| `handler`        | Handler name and version                                                            |
| `payload`        | Codec between the typed payload and stored JSON                                     |
| `idempotencyKey` | Pure function of durable facts. A repeat of the same fact must produce the same key |
| `partitionBy`    | Function that selects the payload's lane                                            |
| `delivery`       | Retry budget and backoff                                                            |

The outbox deduplicates by sink name and idempotency key across all lanes. Changing the partition does not make a repeated key new.

## `CheckedActionSink`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { ActionSinkRelation, ActionSinkSpec } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface CheckedActionSink<
  Payload,
  From extends ActionSinkRelation = ActionSinkRelation,
> extends ActionSinkSpec<Payload, From> {
  readonly kind: "checked-action-sink";
  readonly key: From["key"];
  readonly fingerprint: string;
}
// ---cut-after---
same<CheckedActionSink<string>, Real.CheckedActionSink<string>>(true);
same<
  CheckedActionSink<number, { readonly key: "id" }>,
  Real.CheckedActionSink<number, { readonly key: "id" }>
>(true);
```

`CheckedActionSink` holds the specification that `defineActionSink` validated, its relation key, and its fingerprint.

| Added field   | Meaning                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------ |
| `kind`        | Discriminant for a checked action sink                                                     |
| `key`         | The value of `from.key`, with its literal type preserved                                   |
| `fingerprint` | Contract identity computed from the sink name, key, handler reference, and delivery policy |

The declaration is shallow-frozen. Its nested objects and functions remain the references from the specification.

## `PayloadOf`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { CheckedActionSink } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
type PayloadOf<Sink> = Sink extends CheckedActionSink<infer Payload, infer _From> ? Payload : never;
// ---cut-after---
same<PayloadOf<CheckedActionSink<string>>, Real.PayloadOf<CheckedActionSink<string>>>(true);
same<
  PayloadOf<CheckedActionSink<number, { readonly key: "id" }>>,
  Real.PayloadOf<CheckedActionSink<number, { readonly key: "id" }>>
>(true);
same<PayloadOf<{ readonly unrelated: true }>, never>(true);
same<PayloadOf<{ readonly unrelated: true }>, Real.PayloadOf<{ readonly unrelated: true }>>(true);
```

`PayloadOf` extracts the payload type from a `CheckedActionSink`. For a type that does not extend `CheckedActionSink`, the result is `never`.
