---
title: Action sinks
description: Reference for the action sink exports in @streamsy/serve/action. They declare payload identity, handlers, and retry policy.
---

```ts
import {
  defineActionSink,
  backoffAfter,
  type ActionSinkRelation,
  type ActionSinkChange,
  type ActionSinkHandlerRef,
  type ActionSinkDeliveryPolicy,
  type ActionSinkPayloadCodec,
  type ActionSinkSpec,
  type CheckedActionSink,
  type PayloadOf,
} from "@streamsy/serve/action";
```

An action sink turns changes to a keyed relation into external effects, such as a notification or a webhook. See [Declare a sink](/docs/projections/actions#declare-a-sink).

## `defineActionSink`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { ActionSinkRelation, ActionSinkSpec, CheckedActionSink } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function defineActionSink<Payload, From extends ActionSinkRelation>(
  spec: ActionSinkSpec<Payload, From>,
): CheckedActionSink<Payload, From>;
// ---cut-after---
same<typeof defineActionSink, typeof Real.defineActionSink>(true);
```

`defineActionSink` checks the retry policy and returns a frozen [`CheckedActionSink`](#checkedactionsink). It does no I/O.

When `maxAttempts` is not an integer of at least 1, `backoffFactor` is below 1, `initialBackoffMs` is negative, or `maxBackoffMs` is below `initialBackoffMs`, `defineActionSink` throws a `TypeError`.

The fingerprint covers the sink name, the relation key, the handler reference, and the delivery policy. It does not cover the payload codec, `idempotencyKey`, or `partitionBy`, so a change to one of these functions keeps the fingerprint. The `key` of the result is `spec.from.key`.

## `backoffAfter`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { ActionSinkDeliveryPolicy } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function backoffAfter(policy: ActionSinkDeliveryPolicy, attempts: number): number;
// ---cut-after---
same<typeof backoffAfter, typeof Real.backoffAfter>(true);
```

`backoffAfter` returns the delay in milliseconds after `attempts` failed attempts. It rounds `initialBackoffMs * backoffFactor ** Math.max(0, attempts - 1)` and caps the result at `maxBackoffMs`. It does not schedule a retry.

## `ActionSinkRelation`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkRelation<Key extends string = string> {
  readonly key: Key;
}
// ---cut-after---
same<ActionSinkRelation<"id">, Real.ActionSinkRelation<"id">>(true);
same<ActionSinkRelation, Real.ActionSinkRelation>(true);
```

`ActionSinkRelation` holds the declared key of the relation that a sink observes. `defineActionSink` copies this key to `CheckedActionSink.key`.

## `ActionSinkChange`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
type ActionSinkChange<Row, Key = string> =
  | { readonly kind: "enter"; readonly key: Key; readonly after: Row }
  | { readonly kind: "update"; readonly key: Key; readonly before: Row; readonly after: Row }
  | { readonly kind: "exit"; readonly key: Key; readonly before: Row };
// ---cut-after---
same<
  ActionSinkChange<{ readonly id: number }, number>,
  Real.ActionSinkChange<{ readonly id: number }, number>
>(true);
same<ActionSinkChange<string>, Real.ActionSinkChange<string>>(true);
```

`ActionSinkChange` is one change to the observed relation: a row enters it, changes in it, or leaves it. An `enter` has the new row in `after`, an `update` has `before` and `after`, and an `exit` has the old row in `before`.

## `ActionSinkHandlerRef`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkHandlerRef {
  readonly name: string;
  readonly version: number;
}
// ---cut-after---
same<ActionSinkHandlerRef, Real.ActionSinkHandlerRef>(true);
```

`ActionSinkHandlerRef` names the handler of a sink and its version. Both fields are part of the sink fingerprint. The reference does not register a handler or look one up.

## `ActionSinkDeliveryPolicy`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkDeliveryPolicy {
  readonly maxAttempts: number;
  readonly initialBackoffMs: number;
  readonly backoffFactor: number;
  readonly maxBackoffMs: number;
}
// ---cut-after---
same<ActionSinkDeliveryPolicy, Real.ActionSinkDeliveryPolicy>(true);
```

`ActionSinkDeliveryPolicy` sets how many times the runtime tries to deliver an entry, and how long it waits between attempts.

| Field              | Meaning                                                                                       |
| ------------------ | --------------------------------------------------------------------------------------------- |
| `maxAttempts`      | The number of attempts, including the first. With 1, the first failure dead-letters the entry |
| `initialBackoffMs` | The delay after the first failed attempt, in milliseconds                                     |
| `backoffFactor`    | The factor that multiplies each later delay                                                   |
| `maxBackoffMs`     | The upper bound on the rounded delay. `Infinity` sets no bound                                |

The outbox stores the time of the next attempt, so the retry deadline survives a restart. [`defineActionSink`](#defineactionsink) throws for a policy outside its limits.

## `ActionSinkPayloadCodec`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkPayloadCodec<Payload> {
  readonly encode: (payload: Payload) => string;
  readonly decode: (value: unknown) => Payload;
}
// ---cut-after---
same<
  ActionSinkPayloadCodec<{ readonly id: string }>,
  Real.ActionSinkPayloadCodec<{ readonly id: string }>
>(true);
```

`ActionSinkPayloadCodec` converts between the typed payload and the JSON text that the outbox stores. `encode` returns the text, and `decode` takes the parsed JSON value. `drain` calls `JSON.parse` before `decode`. When either step throws, `drain` dead-letters the entry as `payload-poison` without calling the handler.

## `ActionSinkSpec`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type {
  ActionSinkRelation,
  ActionSinkDeliveryPolicy,
  ActionSinkHandlerRef,
  ActionSinkPayloadCodec,
} from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface ActionSinkSpec<Payload, From extends ActionSinkRelation = ActionSinkRelation> {
  readonly name: string;
  readonly from: From;
  readonly handler: ActionSinkHandlerRef;
  readonly payload: ActionSinkPayloadCodec<Payload>;
  readonly idempotencyKey: (payload: Payload) => string;
  readonly partitionBy: (payload: Payload) => string;
  readonly delivery: ActionSinkDeliveryPolicy;
}
// ---cut-after---
same<ActionSinkSpec<string>, Real.ActionSinkSpec<string>>(true);
same<
  ActionSinkSpec<number, { readonly key: "id" }>,
  Real.ActionSinkSpec<number, { readonly key: "id" }>
>(true);
```

`ActionSinkSpec` declares the relation, the handler, the payload codec, the idempotency key, the lane, and the retry policy of a sink.

| Field            | Meaning                                                                                  |
| ---------------- | ---------------------------------------------------------------------------------------- |
| `name`           | The sink name. The outbox deduplicates entries by this name and the idempotency key      |
| `from`           | The observed relation, with its declared key                                             |
| `handler`        | The handler name and version                                                             |
| `payload`        | The codec between the typed payload and the stored JSON                                  |
| `idempotencyKey` | A pure function of durable facts. Two enqueues of the same fact must return the same key |
| `partitionBy`    | The function that returns the lane of a payload                                          |
| `delivery`       | The retry policy                                                                         |

The outbox deduplicates by sink name and idempotency key across all lanes, so a repeated key stays a duplicate when its lane changes.

## `CheckedActionSink`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { ActionSinkRelation, ActionSinkSpec } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
interface CheckedActionSink<
  Payload,
  From extends ActionSinkRelation = ActionSinkRelation,
> extends ActionSinkSpec<Payload, From> {
  readonly kind: "checked-action-sink";
  readonly key: From["key"];
  readonly fingerprint: string;
}
// ---cut-after---
same<CheckedActionSink<string>, Real.CheckedActionSink<string>>(true);
same<
  CheckedActionSink<number, { readonly key: "id" }>,
  Real.CheckedActionSink<number, { readonly key: "id" }>
>(true);
```

`CheckedActionSink` is the declaration that `defineActionSink` returns: the specification with three more fields.

| Added field   | Meaning                                                                                            |
| ------------- | -------------------------------------------------------------------------------------------------- |
| `kind`        | Always `"checked-action-sink"`                                                                     |
| `key`         | The value of `from.key`, with its literal type                                                     |
| `fingerprint` | The contract fingerprint of the sink name, the key, the handler reference, and the delivery policy |

`defineActionSink` freezes the declaration but not its nested objects. The nested objects and functions are the same objects as in the specification.

## `PayloadOf`

```ts
// ---cut-start---
import type * as Real from "@streamsy/serve/action";
import type { CheckedActionSink } from "@streamsy/serve/action";
import { same } from "./reference-check.ts";
// ---cut-end---
type PayloadOf<Sink> = Sink extends CheckedActionSink<infer Payload, infer _From> ? Payload : never;
// ---cut-after---
same<PayloadOf<CheckedActionSink<string>>, Real.PayloadOf<CheckedActionSink<string>>>(true);
same<
  PayloadOf<CheckedActionSink<number, { readonly key: "id" }>>,
  Real.PayloadOf<CheckedActionSink<number, { readonly key: "id" }>>
>(true);
same<PayloadOf<{ readonly unrelated: true }>, never>(true);
same<PayloadOf<{ readonly unrelated: true }>, Real.PayloadOf<{ readonly unrelated: true }>>(true);
```

`PayloadOf` is the payload type of a `CheckedActionSink`, and `never` for any other type.
