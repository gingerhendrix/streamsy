---
title: Alchemy
description: Reference for the host exports in @streamsy/serve/alchemy. They adapt routing, object clients, and object handlers to Alchemy Effects.
---

```ts
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
```

The Alchemy host provides Effect handlers for an Alchemy Durable Object and its Worker. See [Alchemy hosting](/docs/hosting/cloudflare#alchemy).

## Alchemy handlers

### `Alchemy.router`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function router(options: {
  readonly objects: Pick<DurableObject, "getByName">;
  readonly prefix?: `/${string}`;
  readonly placement?: Alchemy.Placement;
}): Effect.Effect<
  HttpServerResponse.HttpServerResponse,
  HttpServerError.HttpServerError,
  HttpServerRequest.HttpServerRequest
>;
// ---cut-after---
same<typeof router, typeof Alchemy.router>(true);
```

`Alchemy.router` forwards the current Effect HTTP request to the object named by placement. It returns a response Effect. Authenticate before evaluating it.

`objects` is an Alchemy namespace binding. The prefix defaults to `/`, and placement defaults to `Placement.byStream()`. The prefix, reserved path, and placement failure rules match [`Cloudflare.router`](/docs/reference/serve/cloudflare#cloudflarerouter). The forwarded request stays unchanged. A stub's `HttpServerError` remains a typed failure.

### `Alchemy.objectFetch`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function objectFetch(objects: Pick<DurableObject, "getByName">): Alchemy.ObjectFetch;
// ---cut-after---
same<typeof objectFetch, typeof Alchemy.objectFetch>(true);
```

`Alchemy.objectFetch` adapts an Alchemy namespace binding to the web request transport that `ObjectStreams.layer` and `ObjectLink.client` accept. It calls `getByName` when the returned transport runs, converts the request into an Effect HTTP request, and converts the response back to a web `Response`.

A stub failure becomes an `HttpClientError` with a `TransportError` reason that retains the original cause.

### `Alchemy.objectHandlers`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function objectHandlers<R = never, L = never>(options: {
  readonly app: ObjectApp<R | L>;
  readonly layer: Layer.Layer<Storage | AlarmSlot | R, StorageFault, L>;
  readonly wakeups?: ReadonlyArray<Alchemy.WakeupSource<Storage | R | L>>;
  readonly links?: ReadonlyArray<Alchemy.LinkClient<L>>;
}): Effect.Effect<Alchemy.ObjectHandlers, never, Scope.Scope>;

// ObjectApp has no exported name. It is the route Layer that the object hosts accept.
type ObjectApp<R = never> = Layer.Layer<
  never,
  never,
  | HttpRouter.HttpRouter
  | HttpRouter.Request.From<"Requires", Storage | Cloudflare.Wakeups | R>
  | HttpRouter.Request.From<"Error", HttpServerRespondable.Respondable>
>;

// AlarmSlot has no exported name. alarmSlotLayer provides this service.
interface AlarmSlot extends Context.ServiceClass.Shape<
  "@streamsy/serve/cloudflare/AlarmSlot",
  {
    readonly current: Effect.Effect<Option.Option<number>, never, never>;
    readonly arm: (at: number) => Effect.Effect<void, never, never>;
    readonly clear: Effect.Effect<void, never, never>;
  }
> {}
// ---cut-after---
same<typeof objectHandlers, typeof Alchemy.objectHandlers>(true);
```

`Alchemy.objectHandlers` creates fetch and alarm handlers that share one lazy acquisition of storage and application services. The instance scope owns that acquisition and releases it when the scope closes.

| Option    | Meaning                                                                   |
| --------- | ------------------------------------------------------------------------- |
| `app`     | Route Layer for local and linked services                                 |
| `layer`   | Local services and storage, including `alarmSlotLayer(state.raw.storage)` |
| `wakeups` | Additional deadline sources, after built-in stream expiry                 |
| `links`   | Clients of streams on other objects, as a plain array                     |

The acquisition, reconciliation, and link clash rules match [`StreamsyObject`](/docs/reference/serve/cloudflare#cloudflarestreamsyobject). A failed acquisition closes its scope, fetch answers 503 with `Retry-After: 1`, and a later call retries. An alarm acquisition failure becomes a defect so the platform can retry.

### `Alchemy.ObjectHandlers`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type ObjectHandlers = {
  readonly fetch: Effect.Effect<
    HttpServerResponse.HttpServerResponse,
    never,
    HttpServerRequest.HttpServerRequest
  >;
  readonly alarm: () => Effect.Effect<void, never, never>;
};
// ---cut-after---
same<ObjectHandlers, Alchemy.ObjectHandlers>(true);
```

`Alchemy.ObjectHandlers` holds the handlers returned by `objectHandlers`. `fetch` uses the current HTTP request. `alarm()` runs one scheduler turn. The platform invokes the alarm separately from fetch.
