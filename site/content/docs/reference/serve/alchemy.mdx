---
title: Alchemy
description: Reference for the host exports in @streamsy/serve/alchemy. They adapt routing, object clients, and object handlers to Alchemy Effects.
---

```ts
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
```

`@streamsy/serve/alchemy` provides the Effect handlers of a Streamsy host on Alchemy: a router for the Worker, and the fetch and alarm handlers of each Durable Object. See [Alchemy](/docs/servers/cloudflare#alchemy).

## Alchemy handlers

### `Alchemy.router`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function router(options: {
  readonly objects: Pick<DurableObject, "getByName">;
  readonly prefix?: `/${string}`;
  readonly placement?: Alchemy.Placement;
}): Effect.Effect<
  HttpServerResponse.HttpServerResponse,
  HttpServerError.HttpServerError,
  HttpServerRequest.HttpServerRequest
>;
// ---cut-after---
same<typeof router, typeof Alchemy.router>(true);
```

`Alchemy.router` returns an Effect that forwards the current HTTP request to the object that placement names, and succeeds with the response of the object. Authenticate the caller before you run this Effect.

`objects` is an Alchemy namespace binding. `prefix` defaults to `/`, and `placement` defaults to `Placement.byStream()`. The rules for the prefix, reserved paths, and placement failures are those of [`Cloudflare.router`](/docs/reference/serve/cloudflare#cloudflarerouter). The object gets the request unchanged. When the stub fails with `HttpServerError`, the Effect fails with the same error.

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";

import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function objectFetch(objects: Pick<DurableObject, "getByName">): Alchemy.ObjectFetch;
// ---cut-after---
same<typeof objectFetch, typeof Alchemy.objectFetch>(true);
```

`Alchemy.objectFetch` turns an Alchemy namespace binding into the `ObjectFetch` transport that `ObjectStreams.layer` and `ObjectLink.client` take. When the transport runs, it calls `getByName`, converts the web request into an Effect HTTP request, and converts the response back to a web `Response`.

When the stub fails, the transport fails with an `HttpClientError` whose reason is a `TransportError` with the original cause.

### `Alchemy.objectHandlers`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function objectHandlers<R = never, L = never>(options: {
  readonly app: ObjectApp<R | L>;
  readonly layer: Layer.Layer<Storage | AlarmSlot | R, StorageFault, L>;
  readonly wakeups?: ReadonlyArray<Alchemy.WakeupSource<Storage | R | L>>;
  readonly links?: ReadonlyArray<Alchemy.LinkClient<L>>;
}): Effect.Effect<Alchemy.ObjectHandlers, never, Scope.Scope>;

// ObjectApp has no exported name. It is the route Layer that the object hosts accept.
type ObjectApp<R = never> = Layer.Layer<
  never,
  never,
  | HttpRouter.HttpRouter
  | HttpRouter.Request.From<"Requires", Storage | Cloudflare.Wakeups | R>
  | HttpRouter.Request.From<"Error", HttpServerRespondable.Respondable>
>;

// AlarmSlot has no exported name. alarmSlotLayer provides this service.
interface AlarmSlot extends Context.ServiceClass.Shape<
  "@streamsy/serve/cloudflare/AlarmSlot",
  {
    readonly current: Effect.Effect<Option.Option<number>, never, never>;
    readonly arm: (at: number) => Effect.Effect<void, never, never>;
    readonly clear: Effect.Effect<void, never, never>;
  }
> {}
// ---cut-after---
same<typeof objectHandlers, typeof Alchemy.objectHandlers>(true);
```

`Alchemy.objectHandlers` returns the fetch and alarm handlers of an Alchemy Durable Object. Both handlers share one acquisition of storage and services, which runs on first use. The scope of the instance owns the acquisition, and releases it when the scope closes.

| Option    | Meaning                                                                                      |
| --------- | -------------------------------------------------------------------------------------------- |
| `app`     | The route Layer. It can use the local and the linked services                                |
| `layer`   | The Layer of local services and storage. It must include `alarmSlotLayer(state.raw.storage)` |
| `wakeups` | More wakeups. They run after stream expiry                                                   |
| `links`   | The clients of streams on other objects, as an array                                         |

The rules for acquisition, reconciliation, and link clashes are those of [`StreamsyObject`](/docs/reference/serve/cloudflare#cloudflarestreamsyobject). When the acquisition fails, the host closes its scope, `fetch` answers 503 with `Retry-After: 1`, and the next call acquires again. When the acquisition fails during an alarm, `alarm` dies, so the platform retries the alarm.

### `Alchemy.ObjectHandlers`

```ts
// ---cut-start---
import * as Alchemy from "@streamsy/serve/alchemy";
import type * as Cloudflare from "@streamsy/serve/cloudflare";
import type * as Workers from "@cloudflare/workers-types";
import type { DurableObject } from "alchemy/Cloudflare";
import type { Context, Effect, Layer, Option, Scope } from "effect";
import type {
  HttpRouter,
  HttpServerError,
  HttpServerRequest,
  HttpServerRespondable,
  HttpServerResponse,
} from "effect/http";
import type { Storage, StorageFault, Streamsy } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type ObjectHandlers = {
  readonly fetch: Effect.Effect<
    HttpServerResponse.HttpServerResponse,
    never,
    HttpServerRequest.HttpServerRequest
  >;
  readonly alarm: () => Effect.Effect<void, never, never>;
};
// ---cut-after---
same<ObjectHandlers, Alchemy.ObjectHandlers>(true);
```

`Alchemy.ObjectHandlers` holds the handlers that `objectHandlers` returns. `fetch` answers the current HTTP request. `alarm()` runs one turn of the wakeup scheduler. The platform calls `alarm` on its own, never from a fetch.
