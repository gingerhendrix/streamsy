---
title: Errors
description: Reference for the protocol errors in @streamsy/core. Each error is a tagged class that you can catch by its tag.
---

```ts
import { OffsetMismatch, StaleEpoch, isProtocolError, type AppendErrorFor } from "@streamsy/core";
```

The stream operations fail with these errors when the protocol rejects a request. Each one is a `Schema.TaggedError`. It is an `Error`, it has a `_tag`, and you can `yield*` it in `Effect.gen`. Catch one by its tag:

```ts
// @filename: streams.ts
export * from "./notes-streams.ts";
// @filename: index.ts
// ---cut---
import { Effect } from "effect";
import { Notes } from "./streams.ts";

const write = Effect.flatMap(Notes, (notes) =>
  notes.append({}, [{ id: "n1", text: "hello" }]),
).pipe(Effect.catchTag("StreamClosed", (error) => Effect.succeed(error.offset)));
```

Each block below shows the `_tag` and the fields of one error. Every error also has `message`, `name` and `stack`. `StreamId` is a branded `string`.

For the faults that are not protocol rejections, such as `StorageFault` and `EncodeFault`, see [Write › Errors](/docs/streams/write#errors).

## Error classes

### `StreamNotFound`

```ts

```

No stream has this id.

### `OffsetMismatch`


The tail is not the `expectedOffset` of the append. `actual` is the tail now. Nothing was written. See [Conditional writes](/docs/streams/write#conditional-writes).

### `CreateConflict`

```ts
// ---cut-start---
import type * as Core from "@streamsy/core";
import type { StreamId } from "@streamsy/core";
import { same, type Fields } from "./reference-check.ts";
// ---cut-end---
interface CreateConflict {
  readonly _tag: "CreateConflict";
  readonly id: StreamId;
  readonly reason?:
    "config-mismatch" | "soft-deleted" | "fork-content-type" | "fork-source-soft-deleted";

```

A create or fork does not match the stream that has this id. `reason` says why. A response over HTTP does not carry the reason, so the remote client leaves it out. `message` describes the conflict.

### `CreateConflictReason`

```ts
// ---cut-start---
import type * as Core from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type CreateConflictReason =
  "config-mismatch" | "soft-deleted" | "fork-content-type" | "fork-source-soft-deleted";
// ---cut-after---
same<CreateConflictReason, Core.CreateConflictReason>(true);
```

| Reason                     | Meaning                                                   |
| -------------------------- | --------------------------------------------------------- |
| `config-mismatch`          | A stream with this id exists with another configuration   |
| `soft-deleted`             | The id belongs to a deleted stream                        |
| `fork-content-type`        | The fork asked for a content type other than the source's |
| `fork-source-soft-deleted` | The fork source was deleted                               |

### `AppendError`

```ts
// ---cut-start---
import type * as Core from "@streamsy/core";
import type {
  AppendBaseError,
  InvalidAppendRequest,
  InvalidEpochSeq,
  OffsetMismatch,
  ProducerGap,
  StaleEpoch,
} from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type AppendError =
  | AppendBaseError
  | InvalidAppendRequest
  | OffsetMismatch
  | StaleEpoch
  | ProducerGap
  | InvalidEpochSeq;
// ---cut-after---
same<AppendError, Core.AppendError>(true);
```

Every error of the protocol append.

### `AppendErrorFor`

```ts
// ---cut-start---
import type * as Core from "@streamsy/core";
import type {
  AppendBaseError,
  AppendErrorFor,
  OffsetMismatch,
  ProducerGap,
  Producer,
  StaleEpoch,
} from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type NoOptions = AppendErrorFor<{}>;
// AppendBaseError

type Conditional = AppendErrorFor<{ expectedOffset: string }>;
// AppendBaseError | OffsetMismatch

type WithProducer = AppendErrorFor<{ producer: Producer.Position }>;
// AppendBaseError | StaleEpoch | ProducerGap
// ---cut-after---
same<NoOptions, AppendBaseError>(true);
same<Conditional, AppendBaseError | OffsetMismatch>(true);
same<WithProducer, AppendBaseError | StaleEpoch | ProducerGap>(true);
```

The errors that an append with options `O` can get. `OffsetMismatch` needs `expectedOffset`. `StaleEpoch` and `ProducerGap` need `producer`. An option that the type of `O` allows counts as set.

## Guards

### `isProtocolError`

```ts
// ---cut-start---
import type * as Core from "@streamsy/core";
import { isProtocolError as real, type ProtocolError } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function isProtocolError(error: { readonly _tag: string }): error is ProtocolError;
// ---cut-after---
same<typeof isProtocolError, typeof real>(true);
```

`true` when the `_tag` of `error` is the tag of a protocol error. The HTTP edge uses it to send every protocol rejection through one mapper.
