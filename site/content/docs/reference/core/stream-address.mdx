---
title: StreamAddress
description: Reference for the StreamAddress namespace in @streamsy/core. An address names one stream and holds its codec.
---

```ts
import { StreamAddress, type StreamId } from "@streamsy/core";
import type { Schema } from "effect";
```

An address names one stream and holds the codec of its items. An address is a plain value: building one needs no service and opens no resource. A stream class builds its addresses with `at(params)`, so most code does not call these functions. See [Templates and addresses](/docs/streams/declare#templates-and-addresses).

The State types follow the [Durable State protocol](https://durablestreams.com/durable-state). Most writers build State changes with [`DurableState`](/docs/reference/core/durable-state) instead of these types.

## Addresses

### `StreamAddress.json`

```ts
// ---cut-start---
import type { Schema } from "effect";
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function json<A, I, RD, RE>(
  id: string,
  options: { readonly schema: Schema.Codec<A, I, RD, RE> },
): StreamAddress.StreamAddress<A, RD, RE>;
// ---cut-after---
same<typeof json, typeof StreamAddress.json>(true);
```

`json` returns the address of a JSON stream, with the content type `application/json`. Its codec encodes each item with `schema` and then serializes it to a JSON string.

### `StreamAddress.bytes`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function bytes(
  id: string,
  options?: { readonly contentType?: string },
): StreamAddress.StreamAddress<Uint8Array>;
// ---cut-after---
same<typeof bytes, typeof StreamAddress.bytes>(true);
```

`bytes` returns the address of a byte stream. The default content type is `application/octet-stream`. An append concatenates its `Uint8Array` items into one request body, and the server stores that body as one message.

### `StreamAddress.state`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function state<const C extends StreamAddress.Collections>(
  id: string,
  options: { readonly collections: C & StreamAddress.ValidCollections<C> },
): StreamAddress.StateAddress<C>;
// ---cut-after---
same<typeof state, typeof StreamAddress.state>(true);
```

`state` returns the address of a Durable State stream, which is a JSON address that also keeps `collections`. Each key of `collections` is the `type` of one collection on the wire. The codec encodes and decodes the changes of every collection and the three State control messages.

### `StreamAddress.StreamAddress`

```ts
// ---cut-start---
import type { Schema } from "effect";
import { StreamAddress, type StreamId } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface StreamAddress<A, RD = never, RE = never> {
  readonly _tag: "Json" | "Bytes";
  readonly id: StreamId;
  readonly contentType: string;
  readonly codec: Schema.Codec<A, string | Uint8Array, RD, RE>;
}
// ---cut-after---
interface Decoding {
  readonly decoding: unique symbol;
}
same<StreamAddress<string>, StreamAddress.StreamAddress<string>>(true);
same<StreamAddress<string, Decoding>, StreamAddress.StreamAddress<string, Decoding>>(true);
```

| Field         | Meaning                                                                                                                |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `_tag`        | `Json` when the server stores each item as one message. `Bytes` when an append concatenates its items into one message |
| `id`          | The stream id                                                                                                          |
| `contentType` | The content type that `create` sends                                                                                   |
| `codec`       | Encodes an item to its wire form, and decodes the wire form back to an item                                            |

`RD` is the set of services that the codec needs to decode, and `RE` is the set of services that it needs to encode.

### `StreamAddress.StateAddress`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface StateAddress<
  C extends StreamAddress.Collections,
  RD = StreamAddress.CollectionsDecodingServices<C>,
  RE = StreamAddress.CollectionsEncodingServices<C>,
> extends StreamAddress.StreamAddress<StreamAddress.CollectionsEvent<C>, RD, RE> {
  readonly collections: C;
}
// ---cut-after---
type C = StreamAddress.Collections;
same<StateAddress<C>, StreamAddress.StateAddress<C>>(true);
```

A `StateAddress` is a JSON address that also keeps its collections. `DurableState.changes` reads the key field of each collection from `collections`.

## Collections

### `StreamAddress.Collection`

```ts
// ---cut-start---
import type { Schema } from "effect";
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface Collection<
  A,
  I,
  RD,
  RE,
  Key extends StreamAddress.StateKey<A> = StreamAddress.StateKey<A>,
> {
  readonly schema: Schema.Codec<A, I, RD, RE>;
  readonly key: Key;
}
// ---cut-after---
type Issue = { readonly id: string; readonly rank: number; readonly done: boolean };
same<Collection<Issue, Issue, never, never>, StreamAddress.Collection<Issue, Issue, never, never>>(
  true,
);
same<
  Collection<Issue, Issue, never, never, "rank">,
  StreamAddress.Collection<Issue, Issue, never, never, "rank">
>(true);
```

A `Collection` describes one collection of a State stream. `schema` is the codec of its values, and `key` names the value field that gives each change its `key`.

### `StreamAddress.Collections`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type Collections = Record<string, StreamAddress.Collection<any, any, any, any, any>>;
// ---cut-after---
same<Collections, StreamAddress.Collections>(true);
```

`Collections` is the record of the collections of a State stream. Each key is the `type` that names the collection on the wire.

### `StreamAddress.ValidCollections`

```ts
// ---cut-start---
import { Schema } from "effect";
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type ValidCollections<C extends StreamAddress.Collections> = {
  readonly [K in keyof C]: C[K]["key"] extends StreamAddress.StateKey<C[K]["schema"]["Type"]>
    ? C[K]
    : { readonly key: StreamAddress.StateKey<C[K]["schema"]["Type"]> };
};
// ---cut-after---
const Issue = Schema.Struct({ id: Schema.String, done: Schema.Boolean });
type Good = { readonly issue: { readonly schema: typeof Issue; readonly key: "id" } };
type Bad = { readonly issue: { readonly schema: typeof Issue; readonly key: "done" } };
same<ValidCollections<Good>, StreamAddress.ValidCollections<Good>>(true);
same<ValidCollections<Bad>, StreamAddress.ValidCollections<Bad>>(true);
```

`ValidCollections` checks at compile time that each `key` names a `string` or `number` field of its own collection. It maps a valid collection to itself, and it maps a collection with a wrong key to a type that allows only valid keys. The compiler then reports the error on the `key` of that collection, and not on the whole record.

### `StreamAddress.StateKey`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type StateKey<A> = {
  [K in keyof A]-?: A[K] extends string | number ? K : never;
}[keyof A];
// ---cut-after---
type Issue = { readonly id: string; readonly rank?: number; readonly done: boolean };
same<StateKey<Issue>, StreamAddress.StateKey<Issue>>(true);
same<StreamAddress.StateKey<Issue>, "id">(true);
```

`StateKey<A>` is the union of the fields of `A` that can be a State key. A field qualifies when its type is `string` or `number`. An optional field does not qualify.

### `StreamAddress.CollectionsEvent`

`CollectionsEvent<C>` is the item type of a State stream: a change to any collection of `C`, or a State control message.

### `StreamAddress.CollectionsChange`


`CollectionsChange<C>` is the union of the changes to every collection of `C`. `type` discriminates the union, so a check of `type` narrows `value` to the value type of that collection.

### `StreamAddress.CollectionsEncodedChange`

```ts
// ---cut-start---
import { Schema } from "effect";
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type CollectionsEncodedChange<C extends StreamAddress.Collections> = {
  [K in keyof C & string]: StateEncodedChange<C[K]["schema"]["Encoded"], K>;
}[keyof C & string];

// StateEncodedChange has no exported name. It is the wire form of one change.
type StateEncodedChange<A, Type extends string = string> =
  | (Omit<StreamAddress.StateUpsert<A, Type>, "headers"> & {
      readonly headers: Omit<StreamAddress.StateHeaders, "operation"> & {
        readonly operation: "insert" | "update" | "upsert";
      };
    })
  | StreamAddress.StateDelete<A, Type>;
// ---cut-after---
const Issue = Schema.Struct({ id: Schema.String, rank: Schema.NumberFromString });
type C = { readonly issue: { readonly schema: typeof Issue; readonly key: "id" } };
same<CollectionsEncodedChange<C>, StreamAddress.CollectionsEncodedChange<C>>(true);
```

`CollectionsEncodedChange<C>` is the wire form of [`CollectionsChange`](#streamaddresscollectionschange). On the wire, an upsert can have the operation `insert`, `update`, or `upsert`. A read decodes all three as `upsert`.

## Changes and controls

### `StreamAddress.isChange`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function isChange<E extends StreamAddress.StateEvent<unknown>>(
  event: E,
): event is Exclude<E, StreamAddress.StateControl>;
// ---cut-after---
same<typeof isChange, typeof StreamAddress.isChange>(true);
```

`isChange` returns `true` for an upsert or a delete, and narrows `event` to a change. Call it before you read the `type` or the `key` of a State item, because a control message has neither.

### `StreamAddress.isControl`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function isControl<E extends StreamAddress.StateEvent<unknown>>(
  event: E,
): event is Extract<E, StreamAddress.StateControl>;
// ---cut-after---
same<typeof isControl, typeof StreamAddress.isControl>(true);
```

`isControl` returns `true` for a control message, and narrows `event` to a `StateControl`. A control message has `headers.control`, and a change has `headers.operation`.

### `StreamAddress.reset`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function reset(options?: { readonly offset?: string }): StreamAddress.StateControl;
// ---cut-after---
same<typeof reset, typeof StreamAddress.reset>(true);
```

`reset` returns a `reset` control message. A reader that receives it clears its materialized state, then applies the items that follow. See [Control messages](/docs/streams/write#control-messages).

### `StreamAddress.snapshotStart`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function snapshotStart(options?: { readonly offset?: string }): StreamAddress.StateControl;
// ---cut-after---
same<typeof snapshotStart, typeof StreamAddress.snapshotStart>(true);
```

`snapshotStart` returns a `snapshot-start` control message. The changes between it and the next `snapshot-end` form a complete snapshot.

### `StreamAddress.snapshotEnd`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function snapshotEnd(options?: { readonly offset?: string }): StreamAddress.StateControl;
// ---cut-after---
same<typeof snapshotEnd, typeof StreamAddress.snapshotEnd>(true);
```

`snapshotEnd` returns a `snapshot-end` control message, which closes the snapshot that `snapshot-start` opened.

When you call one of the three control functions without `offset`, the control message has no `headers.offset` key:

```ts
import { StreamAddress } from "@streamsy/core";

const controls = [StreamAddress.snapshotStart(), StreamAddress.snapshotEnd({ offset: "42" })];
```

`controls[0].headers` is `{ control: "snapshot-start" }`, and `controls[1].headers` is `{ control: "snapshot-end", offset: "42" }`.

### `StreamAddress.stateChange`

```ts
// ---cut-start---
import type { Schema } from "effect";
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
declare function stateChange<A, I, RD, RE, const Type extends string>(options: {
  readonly schema: Schema.Codec<A, I, RD, RE>;
  readonly type: Type;
}): Schema.Codec<StreamAddress.StateChange<A, Type>, StateEncodedChange<I, Type>, RD, RE>;

// StateEncodedChange has no exported name. It is the wire form of one change.
type StateEncodedChange<A, Type extends string = string> =
  | (Omit<StreamAddress.StateUpsert<A, Type>, "headers"> & {
      readonly headers: Omit<StreamAddress.StateHeaders, "operation"> & {
        readonly operation: "insert" | "update" | "upsert";
      };
    })
  | StreamAddress.StateDelete<A, Type>;
// ---cut-after---
same<typeof stateChange, typeof StreamAddress.stateChange>(true);
```

`stateChange` returns the codec for the upserts and deletes of one collection. `state` builds one of these codecs for each collection. When an optional header has no value, leave its key out. The codec rejects a header that is set to `undefined`.

### `StreamAddress.StateChange`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
type StateChange<A, Type extends string = string> =

// ---cut-after---
same<StateChange<number>, StreamAddress.StateChange<number>>(true);
same<StateChange<number, "n">, StreamAddress.StateChange<number, "n">>(true);
```

`StateChange` is an upsert or a delete in one collection. `headers.operation` discriminates the two.

### `StreamAddress.StateUpsert`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface StateUpsert<A, Type extends string = string> {
  readonly type: Type;
  readonly key: string;
  readonly value: A;
  readonly headers: StreamAddress.StateHeaders & { readonly operation: "upsert" };
}
// ---cut-after---
same<StateUpsert<number>, StreamAddress.StateUpsert<number>>(true);
same<StateUpsert<number, "n">, StreamAddress.StateUpsert<number, "n">>(true);
```

`StateUpsert` inserts or updates the row `key` in the collection `type`, and `value` is the new row.

### `StreamAddress.StateDelete`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---
interface StateDelete<A, Type extends string = string> {
  readonly type: Type;
  readonly key: string;
  readonly old_value?: A;

// ---cut-after---
same<StateDelete<number>, StreamAddress.StateDelete<number>>(true);
same<StateDelete<number, "n">, StreamAddress.StateDelete<number, "n">>(true);
```

`StateDelete` deletes the row `key` from the collection `type`. When the writer sent the deleted row, `old_value` holds it.

### `StreamAddress.StateHeaders`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---

  readonly operation: "upsert" | "delete";

```

`StateHeaders` holds the headers of a change. When `offset` or `txid` has no value, leave its key out instead of setting it to `undefined`.

### `StreamAddress.StateControl`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";
import { same } from "./reference-check.ts";
// ---cut-end---

// ---cut-after---

```

`StateControl` is a control message. It has no `type` and no `key`.

### `StreamAddress.StateControlName`

```ts
// ---cut-start---
import { StreamAddress } from "@streamsy/core";

```

`StateControlName` is the name of a State control message. Section 4.2 of the Durable State protocol defines the three names.
