description: Reference for the constructors of the Projection namespace in @streamsy/projection. A constructor declares a projection over input streams, and its at method binds the params.
---

```ts
import {
  Projection,
  type Accumulated,
  type CheckpointStore,
  type Commit,
  type Declaration,
  type Emits,
  type Emitted,
  type Entry,
  type Folded,
  type Slices,
  type StateDefinition,
  type Step,
  type Unit,
} from "@streamsy/projection";
import type { StreamRoute } from "@streamsy/core/protocol";
import type { Effect } from "effect";
```

A constructor returns an inert [`Declaration`](/docs/reference/projection/declarations#declaration). Its `at(params)` binds the params, and a [runner](/docs/reference/projection/runners) runs the bound projection. See [Define and run](/docs/projections/define).

The signatures use types that have no exported name, such as `Common`, `Addresses`, and `RunningDeclaration`. [Types with no exported name](#types-with-no-exported-name) shows each one.

Every constructor takes the fields of `Common`:

| Field        | Meaning                                                                                                                                                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `id`         | The projection name. It is part of the checkpoint key                                                                                                                                                                          |
| `generation` | The checkpoint generation. The default is `1`. A new generation has no checkpoint, so it reads each input from the start                                                                                                       |
| `params`     | The param codecs, by name. Use `{}` for a projection with no params                                                                                                                                                            |
| `inputs`     | The input streams, by name: stream declarations, fixed addresses, or both                                                                                                                                                      |
| `accepted`   | Optional wake class, with or without `Projection.perGeneration`, for accepted input offsets. Requires `Commit.transaction`, `Commit.ownerTransaction`, or `Commit.producer`. See [Accepted stream](/docs/projections/accepted) |

A defined `version` option throws `RangeError` at declaration time. [Migrate a declaration that set `version`](/docs/projections/checkpoints#migrate-a-declaration-that-set-version)

Each stream declaration in `inputs`, `outputs`, or `accepted` must declare a subset of `params` with the same types. `Projection.perGeneration` supplies one output route parameter from the projection's `generation`. Omit that parameter from `params`. The compiler rejects a field with incompatible params. A fixed address takes no params from the projection. See [Generation-addressed outputs](/docs/projections/outputs#generation-addressed-outputs).

### `Projection.perGeneration`

Use `Projection.perGeneration(route, generationParam, { routeBy: ["workspace", "date"] })` when a single binding writes to several routes. Each name in `routeBy` must be a distinct route parameter supplied by the handler. The generation parameter comes from the declaration and the remaining route parameters come from the binding with matching decoded types.

Routed outputs are exclusively owned by their generation. Declare them in `Projection.process` with `Commit.transaction` or `Commit.ownerTransaction`. Both commits have cleanup variants that also support routed outputs. In the handler, `outputs[name].open(routeParams)` returns the stream address and creates the stream on first use. The first open requires an empty, open stream. Opening the stream, registering ownership, appending changes and saving the checkpoint can all commit in the same transaction. Open handles inside `process`, since `prepare` runs before the transaction.

A live route record is the ownership proof. On later opens, Projection trusts the record and returns the address without checking the stream again. Removing or recreating a routed stream outside Projection is unsupported. To recover, raise `generation`, rebuild, and retire the old generation.

A hand-written handler gets the stream error from its own append, such as `StreamNotFound`. Attached runners retry that error. Map a missing owned stream to a non-retryable fault such as `ProjectionFault` with reason `invalid-output`. [Projection faults](/docs/reference/projection/faults)

Routed outputs appear in the handler's `outputs`. A bound projection's `streams` and `Projection.createOutputs` handle the outputs with a single fixed address.

`fold` declares a projection that folds each entry of a unit into one state value. Each local input entry has `entry.offset`, the storage cursor just after that item; reading from it resumes after the entry. HTTP input entries omit it. The runner calls the `fold` handler once for each entry, in [`Projection.items`](/docs/reference/projection/runners#projectionitems) order, with the value that the previous call returned. The handler returns the next value, or an Effect of it.

- `state` sets the schema and the initial value. See [`StateDefinition`](/docs/reference/projection/declarations#statedefinition).
- `commit` is required when `accepted` is set. Use `Commit.transaction`, `Commit.ownerTransaction`, or `Commit.producer`. Otherwise `commit` defaults to `Commit.checkpoint`, which saves the encoded value and input offsets in one compare-and-set write.
- After each unit, the runner encodes the value with `state.schema`. When the value does not encode, the unit fails with a `ProjectionFault` with phase `process` and reason `invalid-output`.
- When the runner retries a unit, it calls the handler again for each entry. Keep the handler free of external effects. With `Commit.transaction`, the SQL of the handler commits with the checkpoint.

### `Projection.process`

The process context includes `attempt`: 1 for a first binding run, increasing after
failed runs under either attach host. Every unit in that run sees the same attempt.
`Projection.run` and `Projection.follow` always supply 1.

`process` declares a projection that runs an effect for each unit. Local slices carry one storage offset per item in `offsets`, with the last equal to `nextOffset` when non-empty. Non-empty HTTP slices have `offsets` undefined. Every empty slice has `offsets: []`, including skipped inputs and timer-only units. The runner calls the `process` handler once for each unit, with one [`Slice`](/docs/reference/projection/units#slice) for each input. The projection keeps no state. To handle one entry at a time, wrap the handler with [`Projection.each`](/docs/reference/projection/runners#projectioneach).

- `commit` is required. `Commit.transaction` and `Commit.ownerTransaction` run `process` in the checkpoint owner’s transaction. `Commit.atLeastOnce` runs it at least once.
- `prepare` is optional with either transaction commit, including a compensation wrapper. An unsupported commit throws `RangeError` with `prepare requires Commit.transaction or Commit.ownerTransaction`.
- The commit runs `prepare` before it opens the transaction, and passes its result to `process` as `context.prepared`. A retry of the unit runs `prepare` again.
- `outputs` is optional. It names the streams that the handler appends to, by name, with the same param rule as `inputs`. `Commit.transaction` and `Commit.ownerTransaction` accept it. An owner commit wrapped with `Commit.withCompensation` is a type error with `outputs`. The Commit checks every output before the handler runs. `prepare` and `process` get the bound addresses as `context.outputs`. The handler writes the outputs. A routed output requires one of the transaction commits. The runtime message is `Routed outputs require Commit.transaction or Commit.ownerTransaction`. See [Declared outputs](/docs/projections/process#declared-outputs).

`emit` declares a projection that maps each entry to output items. The runner calls the `emit` handler once for each entry, in [`Projection.items`](/docs/reference/projection/runners#projectionitems) order. The handler returns an [`Emits`](/docs/reference/projection/declarations#emits) object, or an Effect of it. The projection keeps no state.

- `outputs` names the output streams. Each entry can be a stream declaration, a fixed address, or a declaration wrapped with `Projection.perGeneration`. Each output must be a JSON or State stream.
- The `Emits` object holds an array of items for each output name. A missing name emits nothing. For a name that `outputs` does not declare, the compiler reports an error on `undeclaredOutput`.
- `commit` is required. `Commit.producer` appends each output with its own producer position. `Commit.transaction` and `Commit.ownerTransaction` append in the checkpoint owner’s transaction.
- `at` throws a `RangeError` when two outputs name the same stream, when an output names an input stream, or when an output is not a JSON or State stream.
- When the value of an output name is not an array, or a change does not fit its collection, the unit fails with a `ProjectionFault` with phase `process` and reason `invalid-output`.

The bound projection also has `streams`, which holds the address of each output after `at` binds the params.

`wake` declares a wake projection, which writes one row to a wake stream for each unit of a source stream. `input` is the source, and `output` is a stream class from [`Streamsy.wake`](/docs/reference/core/wake#streamsywake). Both must declare a subset of `params`.

- Each unit appends one upsert `{ stream, offset, closed? }` with `Commit.producer`. Several source writes in one unit give one row, and the server answers a retry of the append with `Duplicate`.
- `offset` is the `nextOffset` of the source slice. `closed` is `true` when the source is closed.
- When the source is removed or expires, the projection appends a delete of its row, and the runner then forgets the binding.
- `Commit.producer` creates a missing wake stream on its own storage owner. A wake stream on another owner must exist before the first append.
- The definition has no `commit` field. The declaration needs `CheckpointStore`, and its state is always `null`.

## Types with no exported name

The constructor signatures use these types. Apart from `WakeOutput`, the package does not export them. This section shows them so that you can read the signatures.

```ts
// ---cut-start---
import { Schema, type Effect } from "effect";
import { Streamsy, type DurableState, type StreamAddress } from "@streamsy/core";
import type { StreamRoute } from "@streamsy/core/protocol";
import {
  Projection,
  type Accumulated,
  type CheckpointStore,
  type Commit,
  type Declaration,
  type Emits,
  type Emitted,
  type Entry,
  type Folded,
  type Identity,
  type InputMap,
  type ProjectionFault,
  type Slices,
  type StateDefinition,
  type StateSchema,
  type Step,
  type Unit,
} from "@streamsy/projection";
import { Drafts, Notes, Workspace } from "./notes-streams.ts";
import { same, type Flat } from "./reference-check.ts";
// Use the type of the private symbol from the public runner signature.
declare const GenerationOutputs: Extract<keyof Parameters<typeof Projection.pass>[0], symbol>;
// ---cut-end---
// A stream declaration. `at` resolves it with the projection params.
type StreamDeclaration = StreamRoute.StreamRoute<any, any> &
  Streamsy.Any & { readonly at: (params: any) => Streamsy.Address<any, any> };

// An input is a stream declaration or a fixed address.
type Input = StreamDeclaration | Streamsy.Address<any, any>;
type Inputs = Readonly<Record<string, Input>>;
type RoutedOutput = Input | Projection.PerGeneration<StreamDeclaration, string>;
type RoutedMap = Readonly<Record<string, RoutedOutput>>;

// The address after `at` binds the params.
type AddressOf<X> =
  X extends Projection.PerGeneration<infer D, string>
    ? ReturnType<D["at"]>
    : X extends StreamDeclaration
      ? ReturnType<X["at"]>
      : X extends Streamsy.Address<any, any>
        ? X
        : never;
type Addresses<I extends RoutedMap> = { readonly [K in keyof I]: AddressOf<I[K]> };

// The fields that every constructor takes. `Within` makes an input `never` when
// its params are not projection params of the same type.
type AcceptedOutput = WakeOutput | Projection.PerGeneration<WakeOutput, string>;
type AcceptedServices<W> = W extends AcceptedOutput ? Services<{ accepted: W }> : never;
type AcceptedResult<Result, W> = W extends AcceptedOutput
  ? Result extends Folded<infer A>
    ? Accumulated<A, {}>
    : Result extends import("@streamsy/projection").WakeAt
      ? Emitted<{}> & Pick<import("@streamsy/projection").WakeAt, "wakeAt">
      : Emitted<{}>
  : Result;
interface Common<
  C extends StreamRoute.ParamCodecs,
  I extends Inputs,
  W = undefined,
  HE = never,
  HR = never,
> {
  readonly retry?: {
    readonly schedule?: import("effect").Schedule.Schedule<unknown>;
    readonly maxAttempts?: number;
    readonly onExhausted?: (
      unit: Unit<StreamRoute.Params<C>>,
      failure: import("@streamsy/projection").RunnerFailure,
    ) => Effect.Effect<void, HE, HR>;
  };
  readonly id: string;
  readonly generation?: number;
  readonly params: C;
  readonly inputs: I & Within<C, I>;
  readonly accepted?: W & OneOutputWithin<C, W>;
}
type Within<C extends StreamRoute.ParamCodecs, I extends Inputs> = {
  readonly [K in keyof I]: InvalidInput<C, I[K]> extends never ? I[K] : never;
};
type InvalidOutput<C extends StreamRoute.ParamCodecs, X> =
  X extends Projection.PerGeneration<infer D, infer N>
    ? Extract<N, keyof C> | Invalid<C, Omit<DeclaredParams<D>, N>>
    : InvalidInput<C, X>;
type OneOutputWithin<C extends StreamRoute.ParamCodecs, X> =
  InvalidOutput<C, X> extends never ? X : never;
type OutputsWithin<C extends StreamRoute.ParamCodecs, D extends RoutedMap> = {
  readonly [K in keyof D]: OneOutputWithin<C, D[K]>;
};
type OneWithin<C extends StreamRoute.ParamCodecs, X> = InvalidInput<C, X> extends never ? X : never;
type InvalidInput<C extends StreamRoute.ParamCodecs, X> = X extends StreamDeclaration
  ? Invalid<C, DeclaredParams<X>>
  : never;
type DeclaredParams<X> = X extends StreamRoute.StreamRoute<infer P, any, any, any> ? P : {};
type Invalid<C extends StreamRoute.ParamCodecs, P> = {
  readonly [Name in keyof P]: Name extends keyof StreamRoute.Params<C>
    ? P[Name] extends StreamRoute.Params<C>[Name]
      ? StreamRoute.Params<C>[Name] extends P[Name]
        ? never
        : Name
      : Name
    : Name;
}[keyof P];

// The item type of one output, and the services of all outputs.
type Item<T> =
  AddressOf<T> extends { readonly collections: infer C extends StreamAddress.Collections }
    ? DurableState.Entry<C>
    : AddressOf<T> extends { readonly codec: Schema.Codec<infer A, any, any, any> }
      ? A
      : never;
type Services<O extends RoutedMap> = {
  [K in keyof O]: AddressOf<O[K]> extends Streamsy.Address<any, infer R> ? R : never;
}[keyof O];

// What a constructor returns. `at` gives the bound projection that runners take.
type RunningDeclaration<
  C extends StreamRoute.ParamCodecs,
  I extends Inputs,
  E,
  R,
  Result,
  P,
  Q,
  S = never,
  OR = never,
  HE = never,
  HR = never,
> = Declaration<
  C,
  Omit<
    Executable<Addresses<I>, E | ProjectionFault, R, Q, Result, P, S, OR>,
    "process" | "prepare" | "state"
  > & {
    readonly state: [S] extends [never] ? undefined : BoundState<S>;
    readonly process: (
      batch: Slices<Addresses<I>>,
      unit: Unit,
      encoded?: string,
    ) => Effect.Effect<Result, E | ProjectionFault, R>;
  },
  HE,
  HR
>;
type OutputDeclaration<
  C extends StreamRoute.ParamCodecs,
  I extends Inputs,
  O extends RoutedMap,
  E,
  R,
  Result,
  P,
  Q,
  A = never,
  OR = never,
  HE = never,
  HR = never,
> = Omit<RunningDeclaration<C, I, E, R, Result, P, Q, A, Services<O> | OR, HE, HR>, "at"> & {
  readonly at: (params: StreamRoute.Params<C>) => ReturnType<
    RunningDeclaration<C, I, E, R, Result, P, Q, A, Services<O> | OR, HE, HR>["at"]
  > & {
    readonly streams: Readonly<Record<string, Streamsy.Address<unknown, Services<O> | OR>>>;
  };
};
type AccumulatingDeclaration<
  C extends StreamRoute.ParamCodecs,
  I extends Inputs,
  O extends RoutedMap,
  A,
  E,
  R,
  P,
  Q,
  OR = never,
  HE = never,
  HR = never,
> = OutputDeclaration<C, I, O, E, R, Accumulated<A, O>, P, Q, A, OR, HE, HR>;

// The bound projection that the runners take, and its bound state.
interface Executable<
  I extends InputMap,
  E,
  R,
  Q,
  Result,
  P = never,
  S = unknown,
  OR = never,
> extends Identity {
  readonly [GenerationOutputs]?: ReadonlyMap<string, { readonly shared: boolean }>;
  readonly inputs: I;
  readonly state?: BoundState<S>;
  readonly streams?: Readonly<Record<string, Streamsy.Address<unknown, OR>>>;
  readonly accepted?: Streamsy.Address<Streamsy.WakeEvent, OR>;
  readonly commit: Commit.Commit<Result, P, Q>;
  readonly prepare?: (batch: Slices<I>, unit: Unit) => Effect.Effect<unknown, E, Q>;
  readonly process: (
    batch: Slices<I>,
    unit: Unit,
    encoded?: string,
    prepared?: unknown,
    attempt?: number,
  ) => Effect.Effect<Result, E, R | P>;
}
interface BoundState<A> {
  readonly schema: StateSchema<A>;
  readonly initial: () => A;
}

// The definition and result of `Projection.wake`.
type WakeOutput<P = any> = StreamDeclaration &
  StreamRoute.StateRoute<P, Streamsy.WakeCollections> & {
    readonly paramCodecs: StreamRoute.ParamCodecs;
  };
interface WakeDefinition<C extends StreamRoute.ParamCodecs, I extends Input, O, W = undefined> {
  readonly accepted?: W & OneOutputWithin<C, W>;
  readonly id: string;
  readonly generation?: number;
  readonly params: C;
  readonly input: I & OneWithin<C, I>;
  readonly output: O & OneWithin<C, O>;
}
type WakeDeclaration<
  C extends StreamRoute.ParamCodecs,
  I extends Input,
  O extends Input,
  W = undefined,
> = AccumulatingDeclaration<
  C,
  { readonly source: I },
  { readonly wake: O },
  null,
  never,
  never,
  never,
  CheckpointStore,
  AcceptedServices<W>
>;

```

| Type                                              | Meaning                                                                                                     |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `Input`, `Inputs`                                 | A stream declaration or a fixed address, and a record of them by name                                       |
| `RoutedOutput`, `RoutedMap`                       | A stream declaration, fixed address, or `Projection.PerGeneration` wrapper, and a record of them by name    |
| `AddressOf`, `Addresses`                          | The addresses of inputs or outputs after `at` binds the params                                              |
| `Common`                                          | The fields that every constructor takes                                                                     |
| `Within`, `OneWithin`                             | Check that each input route param is a projection param of the same type                                    |
| `OutputsWithin`, `OneOutputWithin`                | Apply the param check to output routes, accounting for the parameter supplied by `Projection.perGeneration` |
| `AcceptedOutput`                                  | A wake class or a wake class wrapped with `Projection.perGeneration`                                        |
| `Item`, `Services`                                | The item type of one output, and the stream services of all outputs                                         |
| `RunningDeclaration`                              | The declaration that `fold` and `process` return                                                            |
| `OutputDeclaration`, `AccumulatingDeclaration`    | The declarations with outputs. Their bound projection also has `streams`                                    |
| `Executable`, `BoundState`                        | The bound projection that the runners take, and its state with `initial` bound to the params                |
| `WakeOutput`, `WakeDefinition`, `WakeDeclaration` | The output, definition, and result of `Projection.wake`                                                     |

`WakeOutput<P>` is the exported type for a `Streamsy.wake` class. Its type parameter is the decoded params; omitting it accepts any wake class. `WakeOutput<{}>` is the fixed-address variant used by `AttachOptions.triggers`.
