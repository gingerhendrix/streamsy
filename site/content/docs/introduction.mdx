This page walks through one small application. Each step shows the call and links the guide that explains it. The program is the same on every host; only the Layer at the end changes.

## 1. Declare streams

A stream class names a set of streams with one id template and one codec. The class is also the service key that a program acquires. A group lists the streams that one host provides and serves.

```ts
import { Schema } from "effect";
import { Streamsy } from "@streamsy/core";

export const OrderEvent = Schema.Struct({ orderId: Schema.String, amount: Schema.Finite });
export const OrderRow = Schema.Struct({ orderId: Schema.String, total: Schema.Finite });

export class Orders extends Streamsy.json<Orders>()("Shop/Orders", "orders", {
  params: {},
  schema: OrderEvent,
}) {}
export class OrderTotals extends Streamsy.json<OrderTotals>()("Shop/OrderTotals", "order-totals", {
  params: {},
  schema: OrderRow,
}) {}
export class OrderEvents extends Streamsy.json<OrderEvents>()(
  "Shop/OrderEvents",
  "orders/:orderId/events",
  { params: { orderId: Schema.String }, schema: OrderEvent },
) {}

export const shop = Streamsy.group(Orders, OrderTotals, OrderEvents);
```

`Orders` has one address, because its template has no parameters. `OrderEvents` has one address per `orderId`. The first argument is a global service name, so give it an application namespace.

See [Streams](/docs/streams/introduction).

## 2. Create and append

```ts
import { Effect } from "effect";
import { Orders } from "./streams.ts";

export const write = Effect.gen(function* () {
  const orders = yield* Orders;
  yield* orders.create({});
  const appended = yield* orders.append({}, [{ orderId: "o-17", amount: 40 }]);
  return appended.offset;
});
```

Every method takes the parameters of one address first. `write` requires the `Orders` service, and the compiler reports a Layer that does not provide it.

See [Creating](/docs/streams/creating) and [Writing](/docs/streams/writing).

## 3. Read and follow

```ts
import { Effect, Stream } from "effect";
import { Orders } from "./streams.ts";

const watch = Effect.flatMap(Orders, (orders) =>
  orders.follow({}).pipe(
    Stream.flatMap((batch) => Stream.fromIterable(batch.items)),
    Stream.runForEach((event) => Effect.log(`${event.orderId}: ${event.amount}`)),
  ),
);
```

See [Reading](/docs/streams/reading).

## 4. Project one stream into another

```ts
import { Effect } from "effect";
import { Projection } from "@streamsy/projection";
import { Orders, OrderTotals } from "./streams.ts";

const projection = Projection.make({
  id: "order-totals",
  input: Orders.at({}),
  process: Projection.each(({ item }) =>
    Effect.flatMap(OrderTotals, (totals) =>
      totals.append({}, [{ orderId: item.orderId, total: item.amount }]),
    ),
  ),
});

export const catchUp = Projection.run(projection);
```

`Orders.at({})` names one address as the projection input. The handler runs inside the checkpoint transaction, so each unit's appends and its checkpoint commit together. `Projection.run` repeats until the input is caught up or the unit limit is reached. `catchUp` requires `Orders`, `OrderTotals`, and the `Checkpoints` service.

See [Projections](/docs/projections/introduction).

## 5. Provide a Layer and run

Start with the memory Layer. Swap it for SQLite when the data has to survive a restart.

```ts
import { Effect } from "effect";
import { Memory } from "@streamsy/core";
import { shop } from "./streams.ts";
import { write } from "./write.ts";

await Effect.runPromise(write.pipe(Effect.provide(Memory.layer({}, shop))));
```

`Checkpoints` comes from `@streamsy/projection/memory` or `@streamsy/projection/sqlite`, over the same storage Layer:

```ts
import { Effect, Layer } from "effect";
import { Memory } from "@streamsy/core";
import * as ProjectionMemory from "@streamsy/projection/memory";
import { catchUp } from "./projection.ts";
import { shop } from "./streams.ts";

const host = ProjectionMemory.layer.pipe(Layer.provideMerge(Memory.layer({}, shop)));

await Effect.runPromise(catchUp.pipe(Effect.provide(host)));
```

```ts
import * as BunStorage from "@streamsy/storage/bun";
import { shop } from "./streams.ts";

export const storage = BunStorage.layer({ client: { filename: "./streams.sqlite" } }, shop);
```

See [Runtime](/docs/runtime/introduction).

## 6. Serve on Bun

```ts
import { Layer } from "effect";
import { HttpRouter } from "effect/unstable/http";
import { BunHttpServer, BunRuntime } from "@effect/platform-bun";
import { Http } from "@streamsy/core";
import { storage } from "./storage.ts";
import { shop } from "./streams.ts";

const server = HttpRouter.serve(Http.routes(shop, { prefix: "/streams", access: "read" })).pipe(
  Layer.provide(storage),
  Layer.provide(BunHttpServer.layer({ port: 3000, idleTimeout: 0 })),
);

BunRuntime.runMain(Layer.launch(server));
```

`Http.routes` serves only the streams in the group. `access: "read"` allows GET and HEAD. An id that no stream owns answers 404, and a write answers 405.

See [HTTP](/docs/runtime/http).

## 7. Deploy to Cloudflare

The same `Http.routes` Layer runs inside a Durable Object. An Alchemy stack declares the object and the Worker in front of it, and `alchemy dev` runs both on your machine.

```bash
alchemy dev
alchemy deploy
```

See [Alchemy](/docs/runtime/alchemy).

## 8. Read it back from anywhere

```ts
import { Layer } from "effect";
import { FetchHttpClient } from "effect/unstable/http";
import * as Fetch from "@streamsy/core/fetch";
import { shop } from "./streams.ts";

export const remote = Fetch.layer(
  {
    baseUrl: "https://streamsy-app.example.workers.dev/streams",
    capabilities: { expectedOffset: true, producer: true },
  },
  shop,
).pipe(Layer.provide(FetchHttpClient.layer));
```

The remote Layer provides the same stream services, so `watch` runs over it without change. A write through it needs `append` or `full` access on the host.

See [HTTP](/docs/runtime/http).

## Choosing a Layer

| Layer                                        | Persists              | Use                 |
| -------------------------------------------- | --------------------- | ------------------- |
| `Memory.layer({}, group)`                    | no                    | one process, tests  |
| `BunStorage.layer(options, group)`           | SQLite file           | Bun host            |
| `DurableObjectStorage.layer(options, group)` | Durable Object SQLite | Cloudflare          |
| `Fetch.layer({ baseUrl }, group)`            | remote                | any conformant host |

The program does not change between Layers. To put streams on different backends, merge one Layer per backend; see [Runtime](/docs/runtime/introduction). For the protocol itself, start with the upstream [quickstart](https://durablestreams.com/quickstart).
