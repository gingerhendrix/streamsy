Streamsy implements the Durable Streams protocol and provides an Effect toolkit
for typed, addressable event streams. This first release contains three packages:

| Package           | Purpose                                                             |
| ----------------- | ------------------------------------------------------------------- |
| `@streamsy/core`  | Protocol services, typed streams, storage contract and memory Layer |
| `@streamsy/serve` | Checked serving contracts and the Bun HTTP host                     |
| `@streamsy/views` | Incremental views and view-store contracts                          |

Effect is the server and toolkit boundary. Browser applications use the official
Durable Streams client and State packages; the [Hacker News demo](/docs/demos/hackernews-newest-stream)
uses `@durable-streams/state` with TanStack DB.

## Storage and hosting

Memory is the only shipped protocol storage backend. Data lasts for the acquired
Layer's lifetime in one process. SQLite protocol storage and Cloudflare hosting
are future work. Package version 0.4.0 uses Effect 4.0.0-rc.112; it does not provide
cross-process persistence or a hosted service.
