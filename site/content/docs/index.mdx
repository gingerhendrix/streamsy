Streamsy is an Effect implementation of the [Durable Streams](https://durablestreams.com/) protocol. It gives you typed refs over streams, projections from one stream into another, and hosts for Bun and Cloudflare.

```ts
import { Effect, Schema, Stream } from "effect";
import { StreamRef, Streams } from "@streamsy/core";

const notes = StreamRef.json("notes", { schema: Schema.Struct({ text: Schema.String }) });

const program = Effect.gen(function* () {
  yield* Streams.create(notes);
  yield* Streams.append(notes, [{ text: "hello" }]);
  return yield* Streams.read(notes).pipe(Streams.items, Stream.runCollect);
});

await Effect.runPromise(program.pipe(Effect.provide(Streams.layerMemory())));
```

## Packages

- `@streamsy/core`: refs, routes, the `Streams` functions, the protocol, the HTTP program, and the memory Layer.
- `@streamsy/storage`: SQLite storage for Bun and for Durable Objects.
- `@streamsy/serve`: the Bun and Cloudflare hosts, and the sink contracts that publish over HTTP.
- `@streamsy/derive`: projections with checkpoints.
- `@streamsy/views`: keyed relations maintained incrementally.
