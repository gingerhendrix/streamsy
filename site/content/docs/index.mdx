Streamsy is an Effect implementation of the [Durable Streams](https://durablestreams.com/) protocol. It gives you typed streams, projections from one stream into another, and hosts for Bun and Cloudflare.

```ts
import { Effect, Schema, Stream } from "effect";
import { Memory, Streamsy } from "@streamsy/core";

class Notes extends Streamsy.json<Notes>()("App/Notes", "notes", {
  params: {},
  schema: Schema.Struct({ text: Schema.String }),
}) {}

const program = Effect.gen(function* () {
  const notes = yield* Notes;
  yield* notes.create({});
  yield* notes.append({}, [{ text: "hello" }]);
  return yield* notes.read({}).pipe(
    Stream.flatMap((batch) => Stream.fromIterable(batch.items)),
    Stream.runCollect,
  );
});

await Effect.runPromise(program.pipe(Effect.provide(Memory.layer({}, Streamsy.group(Notes)))));
```

A stream class is the service key. The program acquires it, and the Layer decides where its streams live.

## Packages

- `@streamsy/core`: streams and groups, the memory Layer, the HTTP routes, and the fetch Layer. The generic protocol services are on the `@streamsy/core/protocol` subpath.
- `@streamsy/storage`: SQLite storage for Bun and for Durable Objects.
- `@streamsy/serve`: HttpRouter routes, Bun and Cloudflare hosts, and action delivery.
- `@streamsy/projection`: checkpointed projections over one or more streams.
- `@streamsy/views`: keyed relations, serializable plan IR, and a pure incremental engine.
