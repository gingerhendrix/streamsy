Streamsy is an Effect implementation of the [Durable Streams](https://durablestreams.com/) protocol:

- Declare byte, json or state streams.
- Create, Read and Append with effects.
- Checkpointed reads with Projections
- Provide storage via layers
- Serve the http protocol

```ts
import { Effect, Schema, Stream } from "effect";
import { MemoryStorage, Streamsy } from "@streamsy/core";

class Notes extends Streamsy.json<Notes>()("App/Notes", "notes", {
  params: {},
  schema: Schema.Struct({ text: Schema.String }),
}) {}

const program = Effect.gen(function* () {
  const notes = yield* Notes;
  yield* notes.create({});
  yield* notes.append({}, [{ text: "hello" }]);
  return yield* notes.read({}).pipe(
    Stream.flatMap((batch) => Stream.fromIterable(batch.items)),
    Stream.runCollect,
  );
});

await Effect.runPromise(program.pipe(Effect.provide(MemoryStorage.layer(Streamsy.group(Notes)))));
```

## Install

The example above needs only `@streamsy/core` and `effect`. Streamsy requires Effect 4.

```sh
bun add @streamsy/core effect
```
