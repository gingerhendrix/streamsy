Every example below is a complete, runnable Streamsy application. Each page walks through what the app builds, how its streams and projections fit together, key code excerpts from the repo, and production notes. All examples live under `examples/` except Doom, which has its own repository.

## Where to start

- **Learn the HTTP protocol:** [Memory server](/docs/examples/memory-server) — a complete Durable Streams server in nine lines, exercised with `curl`.
- **Event sourcing in one file:** [Todo](/docs/examples/todo) — per-list JSON event streams, `Projection.decide`, and background checkpoints.
- **Live browser sync:** [Issue tracker](/docs/examples/issue-tracker) — Durable State + optimistic writes with swappable server and client variants.
- **Try hosted live demos:** [Yjs editor](/docs/examples/yjs-editor) ([yjs-editor.streamsy.dev](https://yjs-editor.streamsy.dev)) and [Doom](/docs/examples/doom) ([doom.streamsy.dev](https://doom.streamsy.dev/)) — binary streams, compaction/snapshots, and Cloudflare Durable Objects.

## All examples

The sidebar lists all 13 top-level examples alphabetically:

| Example                                                       | What it builds                                                                                           | Host & clients                                  |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------- |
| [Bugsy](/docs/examples/bugsy)                                 | Headless issue-tracker server with five workspace inputs, SQL tables, and three derived output streams   | Bun (SQLite, Postgres, or MySQL)                |
| [Command stream](/docs/examples/command-stream)               | Local command worker with caller-key deduplication and transactional accepted receipts                   | Bun + SQLite                                    |
| [Doom](/docs/examples/doom)                                   | Browser Doom recorded as binary input streams with rewind snapshots, native forks, live HUD, and lobby   | Cloudflare Durable Objects + Bun; live demo     |
| [Durable response](/docs/examples/durable-response)           | Four demos that record a scripted AI response, share it across tabs, and stop it for every reader        | Bun + SQLite; React and Foldkit                 |
| [Fold agent](/docs/examples/fold-agent)                       | CLI AI agent whose durable session log fences competing writers with `expectedOffset`                    | Bun + SQLite CLI                                |
| [Folder sync](/docs/examples/folder-sync)                     | Versioned file workspace with SHA-256 blobs, FTS5 search, live browser UI, disk mirror CLI, and agent FS | Bun (SQLite) & Cloudflare (DO + R2); React, CLI |
| [Hacker News newest](/docs/examples/hackernews-newest-stream) | Live feed of the 50 newest HN stories reconciled into Durable State with conditional appends             | Bun + SQLite; React + TanStack DB               |
| [Hex board](/docs/examples/hex-board)                         | Strategy game events folded into one checkpointed board record with SQLite restart tests                 | Bun + SQLite test suite                         |
| [Issue tracker](/docs/examples/issue-tracker)                 | Collaborative issue tracker with optimistic writes, `txid` confirmation, and WIP limits                  | Bun (memory or SQLite); React + TanStack DB     |
| [Memory server](/docs/examples/memory-server)                 | Minimal wildcard Durable Streams HTTP server with a one-layer SQLite swap                                | Bun (memory)                                    |
| [Timer stream](/docs/examples/timer-stream)                   | One-shot and cron timers in Durable State multiplexed onto one SQLite due table and shared wake          | Bun + SQLite                                    |
| [Todo](/docs/examples/todo)                                   | Single-file event-sourced todo HTTP API with background checkpoints and read-only stream mount           | Bun (memory or SQLite)                          |
| [Yjs editor](/docs/examples/yjs-editor)                       | Collaborative ProseMirror editor with binary Yjs updates, expiring awareness, and alarm compaction       | Cloudflare Durable Objects; live demo           |

**Issue tracker variants:** The [Issue tracker](/docs/examples/issue-tracker) shares one wire contract (`issue-tracker-demo-contract`) across swappable implementations. Swap the server with [Event sourced](/docs/examples/issue-tracker/event-sourced), or swap the browser with [Foldkit](/docs/examples/issue-tracker/foldkit) or [Effect Atom](/docs/examples/issue-tracker/atom).
