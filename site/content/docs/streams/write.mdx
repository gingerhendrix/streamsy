## Append

```ts
import { Effect } from "effect";
import { Notes } from "./streams.ts";

const write = Effect.gen(function* () {
  const notes = yield* Notes;
  const result = yield* notes.append({}, [{ id: "n1", text: "hello" }]);
  return result.offset;
});
```

`append(params, items, options?)` encodes the items and writes them as one atomic append.

| Result      | Meaning                                                      |
| ----------- | ------------------------------------------------------------ |
| `Appended`  | Written. `offset` is the new tail and the next read position |
| `Duplicate` | This producer position was already accepted                  |

| Option           | Effect                                     |
| ---------------- | ------------------------------------------ |
| `close`          | Closes the stream after the items          |
| `producer`       | Sends a producer position for safe retries |
| `expectedOffset` | Writes only if the tail equals this offset |

A JSON stream keeps one message for each item. A bytes stream joins the items of one append into one message.

## Durable State changes

`DurableState.changes` makes the change events for one address of a `Streamsy.state` stream.

```ts
import { Effect } from "effect";
import { DurableState } from "@streamsy/core";
import { Workspace } from "./streams.ts";

const createIssue = (offset: string, issue: { id: string; projectId: string; title: string }) =>
  Effect.gen(function* () {
    const workspace = yield* Workspace;
    const params = { workspaceId: "main" };
    const facts = DurableState.changes(Workspace.at(params), { offset }, [
      DurableState.upsert("issue", issue),
    ]);
    yield* workspace.append(params, facts);
  });
```

| Field    | Value                                                                       |
| -------- | --------------------------------------------------------------------------- |
| `key`    | The collection key field of an upserted value, or the key given to `remove` |
| `offset` | The source offset you give                                                  |
| `txid`   | `${offset}:${index}`, unless the change sets it                             |

`DurableState.remove("issue", id)` deletes by key. Add `{ oldValue }` to also write `old_value`. If you give no `offset`, the events have no `offset` and no default `txid`. An upsert or delete can also set `timestamp` or `from`. A change to an undeclared collection, or a value that does not match its schema, does not compile.

## Close

```ts
import { Effect } from "effect";
import { Notes } from "./streams.ts";

const close = Effect.flatMap(Notes, (notes) => notes.append({}, [], { close: true }));
```

Later appends fail with `StreamClosed`.

## Producer retries

A producer position is `{ producerId, producerEpoch, producerSeq }`. `Producer.next` advances it.

```ts
import { Effect } from "effect";
import { Producer } from "@streamsy/core";
import { Notes } from "./streams.ts";

const importOne = (position: Producer.Position) =>
  Effect.gen(function* () {
    const notes = yield* Notes;
    const result = yield* notes.append({}, [{ id: "n3", text: "retried" }], {
      producer: position,
    });
    // Appended and Duplicate both acknowledge this position.
    return { result, next: Producer.next(position) };
  });
```

Advance the position only after `Appended` or `Duplicate`. Send the same bytes on a retry. The server compares positions, not payloads.

| Case                         | Result        |
| ---------------------------- | ------------- |
| Next `producerSeq`           | `Appended`    |
| Accepted `producerSeq` again | `Duplicate`   |
| Skipped `producerSeq`        | `ProducerGap` |
| Older `producerEpoch`        | `StaleEpoch`  |

`producerSeq` starts at 0 for each new epoch. For restarts, see the [core producer restart contract](https://github.com/gingerhendrix/streamsy/blob/effect/packages/core/README.md#producer-restarts) and [PROTOCOL.md section 5.2.1](https://github.com/durable-streams/durable-streams/blob/main/PROTOCOL.md#521-idempotent-producers).

## Conditional writes

`expectedOffset` writes only if the tail still equals it. `ZERO_OFFSET` means the stream must be empty. A miss writes nothing and fails with `OffsetMismatch`, with `expected` and `actual`.

```ts
import { Effect, Stream } from "effect";
import { ZERO_OFFSET } from "@streamsy/core";
import { Orders, apply, initial } from "./orders.ts";

const reserve = (sku: string) =>
  Effect.gen(function* () {
    const orders = yield* Orders;
    const empty: string = ZERO_OFFSET;
    const folded = yield* orders.read({}).pipe(
      Stream.runFold(
        () => ({ state: initial, tail: empty }),
        (acc, batch) => ({
          state: batch.items.reduce(apply, acc.state),
          tail: batch.nextOffset,
        }),
      ),
    );
    if (folded.state.reserved.has(sku)) return { _tag: "Rejected" as const };
    const appended = yield* orders.append({}, [{ type: "reserved", sku }], {
      expectedOffset: folded.tail,
    });
    return { _tag: "Committed" as const, offset: appended.offset };
  }).pipe(Effect.retry({ while: (error) => error._tag === "OffsetMismatch", times: 5 }));
```

A competing writer moves the tail, so the append fails and the retry reads again. To give one writer ownership of a stream, use a producer epoch.

`expectedOffset` is a Streamsy extension to the protocol. See [Extensions](/docs/http/routes#extensions).

### Read, fold, append

The [issue tracker](/docs/demos/issue-tracker#5-read-fold-append) puts this pattern in one function, `IssueTracker.mutate`:

```ts
const mutate = <A, E>(
  workspaceId: string,
  attempt: (state: WorkspaceState) => Effect.Effect<Mutation<A>, E>,
) =>
  Effect.gen(function* () {
    const { state, headOffset } = yield* materialize(workspaceId);
    const { change, value } = yield* attempt(state);
    const ack = yield* append(workspaceId, change, headOffset);
    return { value, awaitOffset: ack.offset };
  }).pipe(
    Effect.retry({
      schedule: Schedule.recurs(3),
      while: Predicate.isTagged("OffsetMismatch"),
    }),
    Effect.catchTag("OffsetMismatch", () => Effect.fail(new WriteConflict({ workspaceId }))),
    Effect.withSpan("IssueTracker.mutate"),
  );
```

`attempt` has no side effects. It returns the change and the answer, or a typed error. A retry runs all of `mutate` again with the new state. After three retries, `mutate` fails with `WriteConflict`.

To project a stream into state and then append, see [Read, decide, append](/docs/projections/state#read-decide-append).

## Errors

| Error            | When                                                             |
| ---------------- | ---------------------------------------------------------------- |
| `StreamClosed`   | The stream is closed                                             |
| `OffsetMismatch` | The tail is not `expectedOffset`                                 |
| `StaleEpoch`     | A higher producer epoch exists                                   |
| `ProducerGap`    | A producer sequence was skipped                                  |
| `AppendConflict` | The content type does not match, or `Stream-Seq` did not advance |
| `EncodeFault`    | An item does not match the codec                                 |

## Over HTTP

`POST` on the stream path appends. It needs `append` or `full` access.

| Header                                          | Carries                  |
| ----------------------------------------------- | ------------------------ |
| `Producer-Id`, `Producer-Epoch`, `Producer-Seq` | The producer position    |
| `Stream-Expected-Offset`                        | The expected tail offset |

The fetch Layer sends these headers only when its `capabilities` allow them. See [Fetch client](/docs/http/fetch).
