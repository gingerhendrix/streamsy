---
title: Hacker News newest
description: Follow newest stories through an Effect server and an official Durable Streams browser client.
---

The server polls Hacker News, writes changes to a JSON source stream and uses a
private, example-local projection bridge to append State facts to a target stream.
The browser consumes the target with `@durable-streams/state/db` and renders
TanStack DB live queries. It shows the newest stories, score and comment changes,
new arrivals and stories leaving the configured set.

## Run locally

From the repository root:

```bash
bun install --frozen-lockfile
bun run --cwd examples/hackernews-newest-stream dev
```

Open http://localhost:1339. `PORT` selects another port. The status view reports
poll counts, projection progress and failures. To run the offline HTTP proof:

```bash
bun run smoke:hackernews
```

The smoke supplies local HN fixtures and checks inserts, updates, deletes and
unchanged-poll suppression through the public target.

## Incubating bridge and bounds

One acquired memory store belongs to one server process. Restarting loses it.
Recovery scans the entire target history and takes progress from fact headers.
Target-tail CAS detects competing output writes.

The bridge treats a whole source read page as one boundary. A backlog above the
item or byte bound can repeatedly reject with `boundary-too-large`; another poll
does not guarantee progress. Raising the relevant bound is necessary for that
page to fit. Recovery scanning itself is outside the catch-up bounds.

This bridge provides no general replay-safe pending writes, owner fencing or
generation activation. It requires at least one output fact per source boundary.
General projection and recovery work is deferred to a later release. The bridge is
incubating and is not a public package API. This demo has not yet adopted the
shipped SQLite Storage Layer; the local Cloudflare Durable Object host is
implemented with workerd evidence, while hosted execution and release
acceptance remain pending. See the [Cloudflare hosting guide](/docs/user/cloudflare-hosting).
