---
title: Hacker News newest
description: Follow newest stories through an Effect server and an official Durable Streams browser client.
---

The server polls Hacker News, writes changes to a JSON source stream, and runs a
fused `@streamsy/projection` that appends State facts to a target stream. The
browser consumes the target with `@durable-streams/state/db` and renders TanStack
DB live queries. It shows the newest stories, score and comment changes, new
arrivals and stories leaving the configured set.

## Run locally

From the repository root:

```bash
bun install --frozen-lockfile
bun run --cwd examples/hackernews-newest-stream dev
```

Open http://localhost:1339. `PORT` selects another port. The status view reports
poll counts, the last run's status and source offset, and failures. To run the
offline HTTP proof:

```bash
bun run smoke:hackernews
```

The smoke supplies local HN fixtures and checks inserts, updates, deletes and
unchanged-poll suppression through the public target.

## The projection

The story index is `Projection.make` over the source ref with a `Projection.each`
handler. Each source command becomes one Durable State fact appended to the target
inside the checkpoint transaction, so a unit's facts and its checkpoint commit
together. Fact headers keep the source position: `offset` is the unit's accepted
source offset and `txid` is that offset joined with the fact's index in the unit.

Source, target and the checkpoint share one memory Layer from
`@streamsy/projection/memory`, held by the runtime that also serves the HTTP
edge. The server runs one bounded `Projection.run` after each poll.
`HN_PROJECTION_LIMIT` caps checkpoint transactions per call.

## Limits

The store is memory only. One acquired memory Layer belongs to one server process,
and restarting the process starts the streams and the checkpoint from empty.

The run is bounded. A `limit-reached` status means later polls continue the
work from the last checkpoint. The server decides the read page size.

The demo makes no hosted claim. It runs on the Bun memory host and has not
adopted the SQLite storage Layer or a Cloudflare deployment. See the
[Cloudflare guide](/docs/runtime/cloudflare) for the hosted path.
