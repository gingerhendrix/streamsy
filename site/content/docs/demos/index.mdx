---
title: Demos
description: Runnable examples of Streamsy's HTTP edge and projection toolkit.
---

[Memory server](/docs/demos/memory-server) is the smallest HTTP host: a Bun
server, one process-local memory store, and a six-step `curl` walkthrough.

[Hacker News newest](/docs/demos/hackernews-newest-stream) polls stories, appends
source changes, runs a fused `@streamsy/projection` over a memory store, and
serves State facts to a live browser collection. Read the demo's limits before
running it.
