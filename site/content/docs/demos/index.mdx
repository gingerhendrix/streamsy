---
title: Demos
description: Runnable examples of Streamsy's HTTP edge and projection toolkit.
---

[Memory server](/docs/demos/memory-server) is the smallest HTTP host: a Bun
server, one process-local memory store, and a six-step `curl` walkthrough.

[Hacker News newest](/docs/demos/hackernews-newest-stream) polls stories into one
State stream and serves it to a live browser collection. Before each append, the
poller runs an atomic projection, reads its rows and offsets with
`Projection.read`, and appends the diff with `expectedOffset`. Its offline smoke
covers replay, live changes, and a departure during a SQLite restart.

[Issue tracker](/docs/demos/issue-tracker) is a complete stream-backed
application. An Effect `HttpApi` decodes each write, then reads and folds the
workspace stream and appends with `expectedOffset`. The same router serves the
stream read-only, and the browser follows it into StreamDB.

[Issue tracker projection](/docs/demos/issue-tracker-projection) feeds five workspace
inputs into atomic SQL and named-output stream addresses, serves rows, transitions
and a compact value, and serializes request and change triggers by address key.

[Hex board](/docs/demos/hex-board) keeps a complete board as fold state in the
checkpoint transaction, with SQLite restart and failed-step persistence tests.

[Fold agent](/docs/demos/fold-agent) stores an agent's session log in one
stream. Each append names the observed tail with `expectedOffset`, so a second
process that writes the same session fences the first one.
