title: HTTP
description: Compose HttpRouter route layers and host them on Bun or a Fetch boundary.
---

`Http.routes` exposes the Durable Streams protocol as an Effect HttpRouter route Layer. One `prefix` controls route registration and protocol path stripping. `Http.app` remains the underlying HttpEffect.

```ts
import { Layer, Schema } from "effect";
import { HttpRouter } from "effect/unstable/http";
import { BunRuntime } from "@effect/platform-bun";
import { Http, StreamRoute } from "@streamsy/core";
import { Serve } from "@streamsy/serve";
import { listener } from "@streamsy/serve/bun";
import * as BunStorage from "@streamsy/storage/bun";

const events = StreamRoute.json("events/:seat", {
  params: { seat: Schema.String },
  schema: Schema.String,
});
const App = Layer.mergeAll(
  Http.routes({ prefix: "/streams" }),
  Serve.stream(events, "/feed/:seat"),
);
const storage = BunStorage.layerProtocol({ client: { filename: "./streams.sqlite" } });
const Server = HttpRouter.serve(App).pipe(
  Layer.provide(storage),
  Layer.provide(listener({ port: 3000 })),
);
BunRuntime.runMain(Layer.launch(Server));
```

The prefix defaults to `/`; `/streams/` normalizes to `/streams`. Bare prefix requests get 400 because they lack a stream id; a neighbouring path gets 404. `maxMessageSize` defaults to 1 MiB, `cacheVisibility` to `private`, and `sseDeadlineMs` to 60,000.

`listener` defaults to `idleTimeout: 0`, so Bun does not close parked long polls after 10 seconds. The route handler is interruptible on the pinned Effect/Bun router: a client abort interrupts a parked long poll and releases its subscription. No extra interruptibility wrapper is needed. Closing the Layer scope stops the listener and releases storage. Bind failures remain typed `ServeError` failures. The application owns logging through the router options.

## Fetch boundary

```ts
const web = HttpRouter.toWebHandler(App.pipe(HttpRouter.provideRequest(storage)), {
  disableLogger: true,
});
// await web.handler(request)
// await web.dispose() at shutdown, including failure paths
```

Effect owns the Request/Response conversion. `Http.makeEdge` is deprecated while the remaining example migrations are completed. There is no Serve `start` helper.

## Protocol

PUT creates or forks, POST appends, GET reads, HEAD reports metadata, DELETE removes, and OPTIONS answers the protocol preflight. A follow uses `live=long-poll` or `live=sse`. A timed-out long poll answers 204 with a cursor. SSE ends at its configured deadline and clients reconnect from their last offset.

Serve routes are read-only even when mounted beneath the protocol prefix; they are not alternate writable ids. See [Serve](/docs/projections/serve) for auth, params, public errors, documents and CORS. For object hosting see [Cloudflare](/docs/runtime/cloudflare) and [Alchemy](/docs/runtime/alchemy).

## Fetch client

```ts
import { FetchHttpClient } from "effect/unstable/http";
import * as Fetch from "@streamsy/core/fetch";

const remote = Fetch.layer({
  baseUrl: "https://streams.example.com/streams",
  capabilities: { expectedOffset: true, producer: true },
}).pipe(Layer.provide(FetchHttpClient.layer));
```

The remote Layer supplies StreamsReader and StreamsWriter. Capabilities are assertions about the host, not discovery. Browser applications use the official Durable Streams client and state packages.
