---
title: Cloudflare
description: Route protocol paths to Durable Objects that own their HttpRouter application and SQLite storage.
---

The Worker placement router forwards each raw protocol path to one Durable Object. The object owns its SQLite, alarm and HttpRouter application.

```ts
import type { DurableObjectNamespace } from "@cloudflare/workers-types";
import { Http } from "@streamsy/core";
import { Placement, StreamsyObject, router } from "@streamsy/serve/cloudflare";
import { layerProtocol } from "@streamsy/storage/durable-object";

interface Env {
  readonly STREAMS: DurableObjectNamespace;
}
export class StreamsObject extends StreamsyObject.make<Env>({
  app: Http.routes({ prefix: "/streams" }),
  layer: (state) => layerProtocol({ client: { storage: state.storage } }),
}) {}
export default router<Env>({
  prefix: "/streams",
  namespace: (env) => env.STREAMS,
  placement: Placement.byKey(() => "streams"),
});
```

Each object lazily acquires one successful storage context and builds `HttpRouter.toWebHandler` once for that acquisition. Concurrent accesses share it. A failed acquisition closes its attempted scope, returns 503 with `retry-after: 1`, and can retry on the next access. The compiled handler and its context share ownership. Object eviction has no universal asynchronous disposal hook. Request logging is disabled in this host.

The host installs global mutation middleware around the application. PUT, POST and DELETE reconcile the alarm in an uninterruptible finalizer, including after an interrupted committed mutation. Reconciliation also runs for rejected PUT, POST and DELETE requests, including a Serve 405. A reconciliation failure cannot replace a committed response. Defects return 500 with the common security headers. The platform alarm calls the expiry sweep directly; no URL or forged request header can invoke it. Sweep failures are left to platform retry and retain the healthy context.

## Placement and limits

`Placement.byStream()` is the default. `Placement.byKey(fn)` groups stream paths. `Placement.byRoute([rule({ route, owner })])` decodes family params before selecting an owner. The first matching rule wins. Empty or unmatched owner keys return 400; throwing placement functions return 500.

Fork source and child must share an object. Placement determines the transaction owner, and must remain stable while data lives under its object names. No cross-object writes are added.

The Worker helper understands protocol URLs only. Serve routes inside an object require application-written Worker routing to select that object; placement does not automatically infer an output owner from a Serve URL. Authenticate before forwarding, and protect every public path to private data.

Projection work runs in an application request middleware or a platform alarm. Use the same storage/SqlClient Layer as its checkpoints and writes. A long-lived follow fiber is not the object hosting model. See [Alchemy](/docs/runtime/alchemy) for the Effect-native host.
