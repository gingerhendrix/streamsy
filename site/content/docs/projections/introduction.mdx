A projection is a named, typed, checkpointed consumer of one or more input streams. It reads a slice of each input, runs an Effect handler over that unit, and commits a checkpoint so a restart resumes where it stopped. A projection can declare optional state with `state:`, kept in the same owner transaction as the checkpoint; see [State](/docs/projections/projections#state).

The kernel is one pass, repeated: restore the checkpoint, read every input in declaration order, run the handler over one unit, commit the checkpoint. `@streamsy/projection` ships two forms of that pass.

- `Projection.atomic` is the atomic form. The handler runs inside the checkpoint owner's transaction, so writes through that owner, a stream on the same storage or SQL through the shared client, commit or roll back together with the checkpoint. A stream write to a stream on another storage owner fails before it runs.
- `Projection.outputs` is the declared-output form. The handler returns items for named outputs: `Output.stream` for typed items and `Output.rows` for Durable State changes. The kernel pins the unit's input ranges in the checkpoint, then appends each output under its own producer tuple. A retry reproduces the pinned ranges and sends the same tuples, so each output sees each unit once. The output streams must share the checkpoint owner; the runner checks that before any write. See [Outputs](/docs/projections/projections#outputs).

Both forms take the optional `state:` and are read with `Projection.read`, which returns the state and the input offsets it is at. The [guarantees table](/docs/projections/projections#guarantees) lists what each form promises.

## Inputs, unit, checkpoint

Inputs are a map of names to addresses, such as `Orders.at({})`. Use `inputs: { input: Orders.at({}) }` for a single input. A runner requires the stream service of every input, plus `Checkpoints`. Every pass hands the handler one slice per declared input, empty or not, and a `Unit` that names the projection and the non-empty ranges of this pass. The checkpoint stores the accepted offset per input, keyed by the same names, and for an outputs projection the pending pin and producer sequence.

## Fact streams and state streams

A fact stream records what happened. Each message is a domain event, appended once and never rewritten. It is the source of truth, and every other stream can be rebuilt from it. Declare it with `Streamsy.json` and an event schema.

A state stream carries the current value of keyed rows. Its items are Durable State change events, and a browser reads it with `@durable-streams/state`. Declare it with `Streamsy.state` and the row schema of the events the projection writes.

```json
{
  "type": "order",
  "key": "o-17",
  "value": { "orderId": "o-17", "sku": "A1", "status": "shipped" },
  "headers": { "operation": "upsert" }
}
```

A state stream is a projection of the facts. A rebuild from the facts writes a new generation of it. See [Durable State](https://durablestreams.com/durable-state).

## Serve

`Serve.stream`, `Serve.state` and `Serve.value` publish streams, Durable State changes and documents as route layers; see [Serve](/docs/projections/serve). `@streamsy/serve/action` delivers external effects.

## A minimal projection

```ts
import { Effect, Schema } from "effect";
import { Streamsy } from "@streamsy/core";
import { Projection } from "@streamsy/projection";

export class Numbers extends Streamsy.json<Numbers>()("Minimal/Numbers", "numbers", {
  params: {},
  schema: Schema.Finite,
}) {}
export class Doubled extends Streamsy.json<Doubled>()("Minimal/Doubled", "doubled", {
  params: {},
  schema: Schema.Finite,
}) {}

/** A stateless atomic map inside the checkpoint transaction. */
export const minimal = Effect.gen(function* () {
  const numbers = yield* Numbers;
  const doubled = yield* Doubled;
  yield* numbers.create({});
  yield* doubled.create({});
  yield* numbers.append({}, [1, 2, 3]);
  return yield* Projection.run(
    Projection.atomic({
      id: "doubled",
      params: {},
      inputs: { input: Numbers },
      process: (batch) =>
        Effect.flatMap(Doubled, (output) =>
          output.append(
            {},
            batch.input.items.map((n) => n * 2),
          ),
        ),
    }).at({}),
    { limit: 10 },
  );
});
```

Provide `ProjectionMemory.layer.pipe(Layer.provideMerge(Memory.layer({}, Numbers, Doubled)))`, with `ProjectionMemory` from `@streamsy/projection/memory`. One run yields `[2, 4, 6]` on `doubled`. Compiled source: `packages/projection/src/examples/minimal.ts`.
