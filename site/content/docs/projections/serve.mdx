title: Serve
description: Publish streams, Durable State changes and documents with Effect HttpRouter route layers.
---

`Serve.stream`, `Serve.state` and `Serve.value` return route Layers. Join them with `Layer.mergeAll`, then use `HttpRouter.serve` or `HttpRouter.toWebHandler`. See [HTTP](/docs/runtime/http) for hosting.

```ts
import { Layer, Schema } from "effect";
import { Http, Streamsy } from "@streamsy/core";
import { Serve } from "@streamsy/serve";

class Events extends Streamsy.json<Events>()("Game/Events", "events/:seat", {
  params: { seat: Schema.String },
  schema: Schema.String,
}) {}
class Cards extends Streamsy.state<Cards>()("Game/Cards", "cards/:seat", {
  params: { seat: Schema.String },
  collections: { cards: { schema: Schema.Struct({ id: Schema.String }), key: "id" } },
}) {}
export const game = Streamsy.group(Events, Cards);

export const App = Layer.mergeAll(
  Http.routes(game, { prefix: "/streams", access: "read" }),
  Serve.stream(Events, "/feed/:seat"),
  Serve.state(Cards, "/state/:seat"),
);
```

A Serve route requires the stream it reads, so `App` requires `Events` and `Cards`. Provide them with a storage Layer for the group. The stream's Schema codecs decode path parameters. Literal route parameters must equal the stream parameters; widened paths are checked at registration. Invalid values get 400, and unmatched paths get the router's 404. Each Serve path owns every method: GET and HEAD read, other methods get 405 with `allow: GET, HEAD`. A Serve URL beneath the protocol prefix is not a second writable id for that stream. Duplicate route shapes fail the Layer build.

State serves the Durable State change stream without a snapshot. A new client reads from `-1`. On `replay-from-start`, clear local rows and replay from `-1`. Replay requires retained history and grows with it. `x-streamsy-state-reset: snapshot` gets 400; no snapshot reset headers are exported.

## Serving declared outputs

`Projection.outputs` accepts stream declarations as output targets. Pass the declaration's `outputs` directly to Serve; the stream codecs still own path parameters. This example is exercised by `packages/projection/test/serve.test.ts`:

```ts
import { Layer, Schema } from "effect";
import { Streamsy } from "@streamsy/core";
import { Output, Projection } from "@streamsy/projection";
import { Serve } from "@streamsy/serve";

const params = { seat: Schema.FiniteFromString };
class Numbers extends Streamsy.json<Numbers>()("Seats/Numbers", "numbers/:seat", {
  params,
  schema: Schema.Finite,
}) {}
class Board extends Streamsy.bytes<Board>()("Seats/Board", "board/:seat", { params }) {}
class Transitions extends Streamsy.bytes<Transitions>()("Seats/Transitions", "transitions/:seat", {
  params,
}) {}
const Card = Schema.Struct({ id: Schema.String, total: Schema.FiniteFromString });
const tracker = Projection.outputs({
  id: "tracker",
  params,
  inputs: { numbers: Numbers },
  outputs: {
    board: Output.rows(Card, { key: "id", stream: Board }),
    transitions: Output.stream(Schema.FiniteFromString, { stream: Transitions }),
  },
  state: { schema: Schema.Struct({ total: Schema.FiniteFromString }), initial: { total: 0 } },
  process: (state, batch) =>
    Effect.sync(() => {
      const total = state.total + batch.numbers.items.reduce((sum, n) => sum + n, 0);
      return {
        state: { total },
        board: [Output.upsert({ id: "total", total }), Output.remove("old")],
        transitions: [total],
      };
    }),
});
const OutputRoutes = Layer.mergeAll(
  Serve.state(tracker.outputs.board, "/board/:seat"),
  Serve.stream(tracker.outputs.transitions, "/transitions/:seat"),
  Serve.value(tracker.state, "/summary/:seat"),
);
```

The target streams supply only ids and the storage owner: each output declaration owns its JSON codec. Run `tracker.at({ seat: 42 })` using the projection host before reading its outputs. Provide that host's `Board` and `Transitions` streams and `State` to the route app. Serve checks outputs without probing inputs or running the projection. An initial absent stream/rows read answers 404; an absent persisted value answers 503 `DocumentUnavailable`. Value schemas must have JSON encoded types to be served (for example, encode dates as strings).

Fixed addresses and targets using fewer parameters share a stream across the matching bound projections, each writing with its own producer id, and Serve exposes that stream at every matching URL.

For a declaration with `params: {}`, its `outputs` are also Serve sources, with no route parameters. Rows use the output name as their collection type and one shared `StateAddress` codec; deletes may omit `old_value`. No read creates a stream, checkpoint, or state row.

## Auth and per-request params

Provide `HttpRouter.middleware` to the route Layer. A `params` Effect on stream or state can read the identity service that middleware supplies:

```ts
const Mine = Serve.stream(Events, "/me", {
  params: Effect.map(CurrentSeat, (seat) => ({ seat: seat.id })),
}).pipe(Layer.provide(SeatAuth.layer));
```

`SeatAuth` declares that it provides `CurrentSeat`, checks the token, and either answers 401 or provides the service around its handler. The params Effect replaces the complete parameter set. Its typed failures remain router request errors for application middleware. A runnable host must satisfy the identity requirement. Protect raw protocol routes too if they expose private data; `Http.routes` serves only the streams in the group you pass, with the access rule you set. An on-demand projection run belongs in application middleware.

## Documents

A value source declares `id`, `paramSchema`, a JSON-encoded `schema`, and `resolve(params)`, an Effect that reads application services. `Serve.value(source, path)` encodes canonical JSON and computes an ETag from those exact bytes. Conditional GET and HEAD support strong and weak validators. Its default cache policy is `private, max-age=0, must-revalidate`. Missing values fail internally with `ValueUnavailable` and return 503 `DocumentUnavailable`.

A projection declaration with `state:` gives `declaration.state`, a value source over the saved state, as in `Serve.value(tracker.state, "/summary/:seat")` above. It answers 503 until the projection has saved its first unit, where `Projection.read` gives the initial value. Its fingerprint is sent in the `x-streamsy-value-contract` header.

The Cloudflare and Alchemy hosts reconcile alarms after PUT, POST and DELETE, including rejected requests such as a Serve 405; see [Cloudflare](/docs/runtime/cloudflare).

## Browser contract and CORS

Import header constants and `decodePublicError` from `@streamsy/serve/contract`; it loads neither Effect nor core. The server's `PublicErrorSchema` is on the package root. Errors distinguish invalid params, incompatible protocol/contract, failed resume, unavailable data and document encoding failures. State and stream errors use replay recovery; documents use refetch.

The `@durable-streams/state` 0.3.1 StreamDB binding merges upserts on an existing key: a field omitted by a later row retains its old value, live and on replay.

A cross-origin app must configure CORS for request contract headers and expose response cursors:

```ts
const Cors = HttpRouter.cors({
  allowedOrigins: ["https://app.example.com"],
  allowedMethods: ["GET", "HEAD", "OPTIONS"],
  allowedHeaders: [
    "authorization",
    "x-streamsy-state-version",
    "x-streamsy-state-contract",
    "x-streamsy-stream-version",
    "x-streamsy-stream-contract",
    "x-streamsy-value-contract",
  ],
  exposedHeaders: [
    "stream-next-offset",
    "stream-cursor",
    "stream-up-to-date",
    "etag",
    "x-streamsy-state-version",
    "x-streamsy-state-contract",
    "x-streamsy-stream-version",
    "x-streamsy-stream-contract",
    "x-streamsy-value-contract",
  ],
});
const BrowserApp = Layer.mergeAll(App, Cors);
```

Fingerprints include the selected stream address and state collection names/keys. `options.contract` supplies an explicit revision when Schema or resolver behavior changes without metadata changing. Fingerprints do not hash functions or replace authorization.

The current protocol uses raw encoded URL ids; Serve resolves decoded stream params. Spaces and non-ASCII params can therefore identify different raw protocol ids. Prefer canonical URL-safe stream segments until the core URL/id policy is unified.
