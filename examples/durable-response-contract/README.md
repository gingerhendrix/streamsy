# Durable response contract

The shared code for the [durable response](../durable-response) server and its [Effect Atom](../durable-response-atom) and [Foldkit](../durable-response-foldkit) pages: the response entry schema, the HTTP API, the fold that turns stream entries into a response view, and the resumable reader with its saved checkpoint. See [streamsy.dev](https://streamsy.dev) for the Streamsy documentation.
